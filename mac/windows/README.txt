UMWELT / 环世界 — Windows 预发布版 0.1.5
作者：五月七日 · https://fivsevn.com

适用于 Windows 10 / 11，64 位 Intel 或 AMD 电脑。
解压后双击 UMWELT.exe。无需安装，不需要另装运行库；首次启动需要解包到系统临时目录，可能稍慢。
请先完整解压，不要在压缩包预览窗口中运行。

游戏与 Mac 版使用同一套内容和界面，可离线游玩。
图鉴、观察记录和设置自动保存在 %APPDATA%\com.fivsevn.umwelt。
关闭后重新打开会保留记录；用新版 EXE 替换旧版也保留记录。
窗口固定为推荐尺寸，标题栏按钮可切换全屏、小窗口或关闭。
资料库、笔记和游戏可独立放置，记录随观察同步更新。

“结束观察”关闭整个应用并保留记录。
“卸载环境”确认后删除当前 UMWELT.exe 及全部专属存档、设置、缓存和日志，不可恢复。
TXT 说明和原始下载 ZIP 由你自行删除。运行时临时文件在退出后清理。

此预发布版尚无 Windows 代码签名，Windows 可能提示未知发布者。
请只从项目官方 GitHub Releases 下载，并自行核对文件来源后决定是否运行。
“查看更新”目前检测正式 Release；预发布更新请查看下面页面。
