# GSM 操作归档

此目录保存 GSM 每轮更新的抽签、素材快照、草稿、审读记录及发布恢复依据。与代码一起保存在 UMWELT 仓库，不需要独立归档仓库或额外访问凭据。仓库公开，因此这些过程记录在 GitHub 上可见；整个目录排除于网站构建，也不进入日常写作阅读包。

工具按 `操作ID/阶段/摘要/` 保存不可变版本，阶段为 `prepared` 或 `reviewed`，每个阶段的 `latest.json` 指向最新版本。归档中的 `manifest.json` 记录源提交与文件校验和，`work/` 保存原操作、阅读包、素材与已有初稿历史，`media/` 保存已引用媒体。修订保留旧版本；不要手工覆盖摘要目录中的文件。

常规保存与恢复使用 `gsm/tools/operation-archive.mjs`，默认写入此目录。临时工作文件仍可放在仓库外，阶段完成后将真实归档提交到本仓库。单纯提交归档不会使原审读失效，实际源内容变化仍须补读、审读。

完整命令、恢复边界及 GitHub Actions 入口见[执行与发布](../docs/publishing.md#持久保存与工作流重放)。准备不会自动写稿或发帖，`reviewed` 仅用于已经完成写作与独立审读的操作。迁移与测试使用隔离目录，不在这里保存测试帖子或伪造的审读记录。
