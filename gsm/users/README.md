# 用户管理

直接编辑下面的表格，提交后 Actions 会自动建立或更新用户文件夹。所有用户使用同一套档案。

新增一行的例子：`| newgecko7 | 新昵称 | 是 | 是 | |`。头像栏留空即可；只修改这份表格并提交到 `main` 也会自动运行 Actions。

- **新增**：增加一行，填写英文数字 `username`、昵称、两个“是/否”开关。无需手工建文件夹。
- **随机转固定**：将“可随机分配”改为“否”。身份、头像和过去的帖子保持不变。
- **停用/恢复**：将“启用”改为“否/是”。停用后保留历史，也不再接受指定或随机的新帖。
- **删除**：没有历史帖子的用户直接删掉表格行，Actions 清理对应文件夹；已有历史的用户请停用，误删会被检查拦住。
- **头像**：不填时，Actions 在同步用户表时就自动分配并保存像素头像，无需先发帖。头像按用户名固定，改昵称或转固定角色不会换脸。自定义头像先放进该用户文件夹，再填文件名；全部生成头像统一保存为 `../assets/avatars/<username>.webp`，用户文件夹只保留档案和自定义原图。
- **改名**：只改昵称；已有历史之后不要改 username。`profile.json` 由本表生成，头像裁剪等高级选项可在该文件中设置。

用户的新增、昵称、头像和开关只在本表管理。trigger 只负责发帖：可指定已注册用户名；留空或无法对应到已注册用户时，从随机池选择，不创建用户、不修改本表。
