# 论坛自身

爬爬在线是这个世界中的守宫社交平台。这里管理平台自身偶尔发生的事情，以及公开交往留下的共同记忆。私人经历和个人关系放在[本人档案](../users/README.md)。

## 触发情境

| 情境 | 可以观察与发展的内容 |
| --- | --- |
| 平台发生变化 | 一则站方公告、服务故障、活动或规则调整，以及不同用户受到的具体影响 |
| 一段交往产生后续 | 旧帖被重新提起、承诺兑现、误会延续或澄清 |
| 多个讨论产生联系 | 一次经历被不同守宫引用，一种叫法逐渐沿用，局部熟悉感积累 |

每轮先观察世界与生活，有相关情境时再发展站内事件。故事里的平台变化通过公开内容表现，网页实际功能按页面维护流程处理。

## 形成公共记忆

从[已归档帖子](../posts/)读完整交流，保留发言先后和当事人真正说过的话。参与、引用和明确回应决定这段记忆的范围；反复交往可以逐渐形成眼熟、信任、分歧或回避。

采用后保留简短条目：稳定事件编号与时间、公开经过与帖子链接、涉及账号和知情范围、仍在持续的后果或可接续位置。候选情节留在创作过程，完整经过由原帖承接。
