# 研究-Meme

这里研究守宫在网上怎样用姿态、图像、熟悉句式和颜文字接话。正式反应资源使用 [GSM 守宫图像](../assets/emotes/gsm/manifest.json)与[本站颜文字](../assets/emotes/kaomoji.json)。内容由它实际接住的话头决定，名称、身体部位或物种标签本身不构成一个梗。

选择与转换边界见[本站化](../docs/localization.md)，媒体数量见[抽签规则](../docs/lottery.md#图片与表情抽取)，制作与归档见[发布说明](../docs/publishing.md#生成并归档配图)。本篇只维护表达观察，不另设每轮必须搜新梗或使用多少表情的任务。

## 从此刻的动作与态度选表达

先看它在回应哪一点：听不懂、懒得解释、想加入热闹、嫌对方炫耀、假装没看见，还是觉得自己的处境好笑。再查看清单中的真实画面和完整颜文字，用当时的语气选择。

趴平可以是无聊、疲惫、装作不在乎；抬爪可以赞同也可以故意敷衍；同一张疑问图会被认真问事的人和装傻的人使用。不能把卡通动作直接认作真实守宫的生物学表情或当前身体状态。

纯图、半句配图、连贴同图和文字颜文字都成立。熟图可以反复出现，不为了每次“创新”换文件或改表情，也不在每个角色结尾添一个相同小尾巴。

## 守宫生活怎样成为话头

| 画面或表达线索 | 实际观察与改编的问题 |
| --- | --- |
| 睡在没被当作床的物件上 | 角色觉得位置够用、想炫耀自己找到了地方，还是嫌别人管太多；人类笑点不自动等于它的想法 |
| 容器里的脚印或踩过的痕迹 | 是回忆刚才的动作、否认被发现，还是只对别人盯着痕迹有反应；不凭痕迹补全行为动机 |
| 尾巴、趾、轮廓与姿态的局部 | 亲眼看到了什么、只是形状联想还是有身体依据；不同物种的外形不能混用 |
| 颜色和纹样的比较 | 喜欢、嫌丑、拉踩、认错或跟着夸都可出现；照片和光照条件不足时，猜测留在说话者口中 |
| 熟悉的网名与旧表情 | 熟悉到什么程度、谁能认出、有没有人看不懂；新来者无需拥有全部共同记忆 |
| 一句日常抱怨被反复套用 | 原句在新处境里改了什么、谁觉得好笑或烦；保留主体的守宫生活，不搬来人类职业模板 |

这些是构思入口，不是指定本轮情节。一个画面也可以只好看，没有梗，没有后续。

## 本站资源的实际使用

清单是可用文件的唯一入口。采用前查看真实图片，按真实画面写 `alt`；颜文字采用清单里的完整 `text`，不从名称猜写。正式 `media.kind` 按用途区分普通图和反应表情。

外部 emoji、平台专有表情和反应图可作为理解来源语气的材料，公开表达按[本站化](../docs/localization.md)转换。图中的普通叶片、布景或脚印，若承担的是具体信息，不因为动物题材就归作表情包。

卡通资源提供拟人化表达，正文中的照片仍核对物种、身体比例、趾和尾部、接触面及取景位置。照片不需要每次出现完整守宫，生活里的表面、藏身处和痕迹也可以成为主角；镜头所见不能越过本人实际接触范围。

## 图像可以怎样参与来回

一个人发具体生活照片，别人用自己的照片比较、圈出一处或回一张熟表情；原作者可以只答“不是那里”，也可以补个局部。图片与正文各自承担多少信息随实际话头变化。

同一图被不同人复用，意义可能改变。有人贴图表示笑，另一个人问“你笑什么”，这一句就给后续提供了具体对象。认真解释、连贴几张和完全不用图的回应可以挨着出现，不把整页修成均匀排版。

截图只展示这个账号确实能看到的站内内容或有依据的界面；制作、绘图等能力沿既有平台设定和角色事实，不能为了一个模板临时补出人类专业设备和精细操作。普通图片、反应图和截图的检查统一见[配图](../docs/writing.md#配图)。

## 近期 Meme 的观察与取用

需要引入新的用法时，从[每日材料](sources-daily-opinions.md)及守宫、爬宠相关原串寻找当前使用，读实际发言和接话；不把泛社交热榜里的流行语机械嫁接过来。近期观察可以纳入已有的 `trend`，不另加一份固定配额。

观察表达时，区分原素材出现时间与这一次的实际使用时间。

只能读到标签就记录标签，实际打开原图后才描述画面；返回缓存、日期未知和未展开的回复都照实保留。熟悉的旧表达可以继续用，没找到合适新梗时照常说普通话。

## 局部用法与共同叫法

一小群账号可以沿用同一个称呼，另一群仍看不懂，也有人故意换词或觉得叫烦了。共同用法只有实际在原帖中被接住、复用以后，才逐步记录传播范围；出现一次不等于全站惯例。

## 内容、形式与立场

Limor Shifman（2013），[Memes in a Digital World: Reconciling with a Conceptual Troublemaker](https://cris.huji.ac.il/en/publications/memes-in-a-digital-world-reconciling-with-a-conceptual-troublemak/)。来源记录（2026-11-09）：作者所在大学的摘要与书目信息。论文将内容、形式与立场分开观察。这里据此分别看这次在说什么、保留了哪种句式或图文关系、说话者带着什么态度；不因用了同一张图就认定意思相同，也不把摘要当成对传播规模的实证证明。

| 观察点 | 实际要辨认的关系 |
| --- | --- |
| 前情 | 表达在回应什么，理解它需要知道哪些事 |
| 重复与变化 | 句式、图文或动作保留了哪一部分，具体细节换在哪里 |
| 使用者与受众 | 谁认出、询问、误解或觉得不好笑 |
| 后续 | 有没有复读、续写、解释、纠正与转话题 |
| 时间与范围 | 原素材出现、条目收录／修订、本次使用与采样各是什么时间 |

[真实社区观察G01—G03](sources-community-observations.md)保留支架睡姿、食碗脚印与名字接龙的来源和具体发现。可以沿用途被重新解释、痕迹被发现、认错出处后的说明研究笑点；人类照料者的玩笑不证明守宫在想同一件事。

### M04｜伸爪动作的改画与重新定向

- **来源与范围**：2026-11-09读取[Know Your Meme目录](https://knowyourmeme.com/memes)、[Snow Leopard Paws at You出处与传播条目](https://knowyourmeme.com/memes/snow-leopard-paws-at-you)及[游戏角色改画原串](https://www.reddit.com/r/DeadlockTheGame/comments/1xeuvr1/paws_at_youleaping_slash/)。原动作照片、条目初建与修订、实际改画分别记录；原串缓存的相对日期不作为近七天证据。
- **观察与用途**：同一个伸爪动作可以保留邀请的形式，又随角色画面与语气改变立场。守宫表情可表达邀请、催促或敷衍，但具体意义由父帖决定；不把雪豹、游戏角色画面当作GSM正式资源，也不据动物原动作推断它在向人类发出相同含义。

## 惯例形成的研究

<a id="centola-baronchelli-2015"></a>

### 局部互动与惯例

**Centola, D. & Baronchelli, A.（2015）**。*The spontaneous emergence of conventions: An experimental study of cultural evolution*。*PNAS* 112(7):1989–1994。DOI [10.1073/pnas.1418838112](https://doi.org/10.1073/pnas.1418838112)；[作者机构公开稿](https://ndg.asc.upenn.edu/wp-content/uploads/2016/04/Centola-Baronchelli-2015-PNAS.pdf)。

**问题与发现：** 命名协调实验中，参与者只作局部互动，网络连接方式的变化会改变惯例形成过程。**采用与边界：** 共同叫法可以先在少数角色间沿用、改写或中断，有传播依据再记录采用范围。实验设有局部协调报酬，并操作了网络结构；本项目没有同样的拓扑与收益模型，不能声称复现其结果，也不要求社区终将形成一致惯例。

## 真实图文交流样本

ME01—ME02的来源记录日期为2026-11-09，后续条目分别记录实际读取范围。这里研究图片怎样在对话中完成表达；动物原图、外部反应图、本站正式表情与截图各有用途，不因为都含图片就当成同一种媒体。

### ME01｜做饭失败后的吐槽与接话

- **来源与范围**：[豆瓣：做饭失败后的吐槽与接话](https://www.douban.com/group/topic/504108531/?_spm_id=MTUxNjQ1MDMz)。已读正文、第一页最赞回复及楼主引用的回复；附图留待查看。页面显示编辑于2026-10-30，原始发布时间未知。
- **参考要点**：先认真夸，括号里突然把试吃推给别人；沿面量变化写递进；给失败的菜换个名字。改编时保留这类动作，再换成当事人的具体处境。

- **守宫应用与边界**：保留认真夸一句后改变语气、递进和给失败结果重新命名的形式；事情要改为守宫能接触的日常，不让守宫做饭或承担试吃人类食物的动作。未看原图时不据标题描写菜。

### ME02｜认出模板与听完仍不理解

- **来源与范围**：[Reddit：这些奇怪的 meme 是什么](https://www.reddit.com/r/OutOfTheLoop/comments/yefe3l/whats_the_deal_with_these_unusual_memes/)。已读主帖及 Best 下返回的部分评论，含 Loss 解释与 The Game 分支；画面和隐藏回复留待查看，原始日期未知。
- **参考要点**：有人认出模板就笑，有人听完解释仍觉得一般，有人只接自己认识的部分。人物可以把反应停在各自理解的地方。

- **守宫应用与边界**：同一个表情与句式可以有人认得、有人听过仍觉得一般，其他人只接一处。是否了解由实际接触决定，不能把所有角色写成共享人类互联网梗库。

### ME03｜现场照片引出另一张生活照片

- **来源与范围**：[Bangumi：收起你们的问号](https://bangumi.tv/group/topic/475382)。原始日期：2026-11-09。2026-11-10读取公开主帖与可见回复，重点核对 #2-2、#4、#8 的正文；网页文字抽取不完整，已用原页 HTML 核对图片位于发言正文内。实际打开主帖与 #2-2 的完整图片：前者为深色汽水里浮着薯条的白纸杯，后者为插着薯条的粉色冰淇淋纸盒及旁边的饮料杯。
- **参考要点**：主帖先放生活照片，回复只用一句简短认同加另一张吃法照片接话；画面本身承担了分享与比较。短文字加照片已经能推进交流，现场图可以同时出现在主帖与回复中。

- **守宫应用与边界**：一张住处、叶片或脚印照片可以引来另一张自己的现场图，短句即可建立比较。原人类汽水、薯条和冰淇淋吃法不赋给守宫，也不把照片反应都改成卡通表情。

### ME04｜同一张站内表情穿插在多人短回复中

- **来源与范围**：[Bangumi：刚来班固米，新人求教](https://bgm.tv/group/topic/405100)。原始日期：2024-09-08。2026-11-10读取主帖及 #2—#13 的可见回复，重点查看 #2、#2-5、#7、#10-4、#10-8、#13-2、#13-6。已打开反复出现的内置表情 `img/smiles/tv/15.gif`，查看其粉色电视脸首帧；动态的后续帧未逐帧读取。
- **参考要点**：不同人会顺手用同一张站内表情，有人在一句短话后连贴三个相同表情，也有人在认真解释中插一张。表情随着具体语句承担调侃、缓和或夸张的语气，同一串的图文密度可以有疏有密。

- **守宫应用与边界**：GSM自己的表情可以被不同账号顺手复用、连贴和反着用，认真解释与短反应的密度也可不同。采用正式守宫清单，不复制原站电视脸，不把首帧所见推广为整个GIF动作。

### ME05｜晒图主帖引来短反应，也能继续补图

- **来源与范围**：[Stage1st：买了新相机就是要狠狠地晒猫片](https://stage1st.com/2b/thread-2273609-1-1.html)。原始日期：2026-01-30。2026-11-10读取主帖和页面16条可见回复，取用晒猫、照片比较与接话方式。实际打开主帖的一张猫片与一张头部局部图；其余图片按原页位置和说明记录，未逐张看图。
- **参考要点**：一组照片承载展示，回复者可以只夸一句猫并带上论坛表情；楼主也会回应建议后再补一张自己的照片。完整画面、局部比较、短反应和后续补图围绕同一话头交替出现。

- **守宫应用与边界**：守宫晒自身纹样或环境图时，完整图、局部比较、短夸和补图可以交替。照相器材、拍猫经历与相机消费不转给守宫，发图沿已有平台设定。

### ME06｜截图直接展示界面，再用短问句指出问题

- **来源与范围**：[Bangumi：Bangumi表情 融合版v1.4.1](https://bangumi.tv/group/topic/437499)。原始日期：2025-09-30。2026-11-10读取公开主帖与回复，重点核对 #12、#13、#55 的正文图片位置；已打开 #12 的截图，画面是粉色小电视表情选择面板。其余两楼的图片按正文位置记录，未逐张看图。
- **参考要点**：回复用两句简短说明和界面截图展示成果，其他楼层用图片配短提问或对照说明。画面交代具体界面和状态，文字只需指出疑问或变化，后面的人即可沿图中的细节继续讨论。

- **守宫应用与边界**：可以只用GSM实际界面截图加短问句指出一处变化；截图必须对应真实可见内容。原站插件开发、编程和表情选择面板不成为守宫专业能力，也不凭未读图片补界面细节。
