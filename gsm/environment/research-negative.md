# 研究-负面与争议

这里研究守宫怎样对生活和网上交往表达不满、嫉妒、猜疑、轻蔑、护短与争胜。矛盾从身体、住处、可见信息、偏好和实际关系里长出来；社会复杂性保留，事情的主体仍是守宫。数量和概率只按[抽签规则](../docs/lottery.md#负面与回复提示)，逐串来回见[评论研究](research-comments.md)。

## 什么算负面

正文或图像实际表达了烦、失望、嫌弃、讥讽、委屈、敌意或怀疑，才作负面判断。可以只嫌一块东西难看、一次挪位置麻烦、别人管得太多，无须有值得开会讨论的事件。语气很轻也可能带攻击，笑脸和玩笑也可以阴阳怪气。

普通询问、仅说明物件状态和中性转述分别保留。问照片为什么缺一块，与说它丑，不是同一种态度；发一张问号守宫也未必在嘲笑。审读按终稿具体作用登记，不为数量要求把普通问句改判为负面。

## 守宫生活里的不满从哪里来

下表是观察和构思方向，不是已发生的角色事实，也不是每轮需要集齐的矛盾清单。

| 具体条件 | 可以保留的复杂性 |
| --- | --- |
| 位置舒服却进退费劲 | 想待着又嫌麻烦，知道要挪仍抱怨；旁人可能嫌它磨叽，也可能只问入口大小 |
| 熟悉路线被挪动的物件挡住 | 对改变不满，但未必知道是谁、为什么改；不能直接复制人类租房维修的整套流程 |
| 自己展示的颜色、姿态或照片被冷落 | 想得到关注又不愿承认，比别人更爱炫耀却反过来嫌别人晒得多 |
| 别人的活动条件与自己不同 | 把自家经验当普遍真理，解释后能改口，也可能恼羞成怒、继续说对方事多 |
| 只看见脚印或局部图 | 猜测、跟风、误读和合理追问并存；图像未证明的行为留在人物的说法里 |
| 网络熟人不回应或只回表情 | 在意被忽略、觉得对方敷衍、替熟人说话；关系边界按实际交流，不添私下约定 |
| 喜欢的纹样、图像或表达遭到贬低 | 审美争论、护短、拉踩和低级玩笑可以没有结论；不必引入人类品牌消费和器材测评 |
| 照料者的动作打断活动 | 角色可以烦、躲开或不理解，不自动知道清理日程和购买安排，也不强写成感恩故事 |

这些不满可以集中在一个串，也可以只是各处一句嫌烦。普通轻蔑与长解释、热心与冷淡都能相邻；不要求正负交替，更不为负面补足受害经过和漂亮反击。

## 信息不足和偏见怎样写

先分清谁亲眼见到、谁只读了文字、谁看过完整图、谁在转述。人物可以因为这些差异猜错，叙述和档案不能跟着把猜测改成事实。

外部爬宠帖里，照料者的“它故意这样”常常是解释或玩笑。采用时先保留可观察动作，再决定守宫愿意怎么说；不能让虚构角色同时知道饲养者的预算、后台记录、医学判断和所有评论。

不同种类的建议可能不适用，指出这一点是异议，不自动叫抬杠。某个角色也可能嫌对方解释太多、把物种差异当借口，或者坚持自己没错。写清它这一句具体抓住什么，不替编辑宣布一方天生有理。

## 异议怎样转成抬杠

最初可能争的是位置、动作或照片细节，后来转向谁有经验、谁爱显摆、谁先冒犯。看回答之后发生了什么：问题缩小、接受一处与继续绕开答案，是不同过程。

争胜可以只抓住一个词。得到解释后改问对方为什么这样解释，用对方生气证明它心虚，宣布不聊又回来抢最后一句，都可以从眼前对话发生。不能凭一句尖话给角色永久贴上“杠精”标签。

旁人可以核对、帮腔、跟着贴图、维护喜欢的账号，也可以完全略过争执继续问自己的问题。一个分支澄清了，不要求另一支同步收场；没升级、中断和无人接招也保留。

## 低级与无序的参与

短促嫌弃、跟风、双标和没说清楚的骂声可以原样停住。人物未必愿意解释，更不必每次把自己的欲望讲得很诚实。对自己宽容、对别人苛刻的落差，可以很小也可以很明显。

无序从实际话头形成：误看一部分、接错一处、重复旧话、突然不回。不要批量删标点或随机添脏话来制造“自然”，也不要把每次嫌弃都磨成机灵的几字金句。

负面不要求危险共居、伤害或养护失误充当素材。真实健康、福利与危险接触问题按适用物种的专业资料核对，故事里人物的判断也不能代替诊断。

## 研究时看什么

从[每日守宫材料](sources-daily-opinions.md)的可读原串继续看：原作者实际希望得到什么，旁人接住了动作、画面还是说话方式，哪一句让下一位改口或顶回去。连同没答上、没争起来和重复的回复一起保留。

当轮案例仍从守宫或爬宠生活取材。人类社会原串可研究嫉妒、偏见、解释资格与争胜机制；应用时须另有自然成立的守宫事情，不把工资、合租账单、办公软件或手工制作经历直接移给守宫。

一份有效观察记清原始日期、访问时间、读取楼层、明确引用关系与缺失部分。未知父帖不从邻接关系补猜，未打开的图不当作看到证据。采用以后仍从[写作与改编](../docs/writing.md)和本人知情范围检查终稿。

### N11｜情境影响不等于固定人格或全网比例

- **来源与范围**：Cheng等，[Anyone Can Become a Troll: Causes of Trolling Behavior in Online Discussions](https://hci.stanford.edu/publications/2017/trolls/troll-cscw2017.pdf)（CSCW 2017）。2026-11-11读取作者PDF第1—2页的摘要、引言和定义，实验细节与后续结果未逐页读取。
- **参考要点**：作者把情绪和前序讨论列为行为触发因素，并区分实验人工编码与新闻社区标记的代理指标。这里借它提醒写作者保留普通人的状态变化；论文包含辱骂、攻击等更广行为，不能直接等同中文“杠精”，也不能把特定社区数字移成本平台或全网比例。
