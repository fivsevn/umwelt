# 上传图片

直接把图片放进这里，提交到 `main` 就会自动发帖。**不需要填写 trigger，不需要手写图片引用。**

- 只传图：一张图一条帖，自动分配一个允许随机发帖的用户，并固定为这条帖子的作者。
- 要配文：写在提交的详细说明中；自定义提交标题也可用作配文，默认的 `Add files via upload` 会忽略。
- 要指定用户或点赞数：详细说明里可写 `---` 配置区，例如 `username: backpackgecko`、`likes: 24`；不指定就用随机用户和 0 个初始点赞。
- 同时编辑 trigger 时可以把多图和正文组合成一条帖，具体见[发帖说明](../docs/publishing.md)。

支持 JPG/JPEG、PNG、WebP、GIF、HEIC/HEIF，自动转换为 WebP，保留透明和动画。原图在**归档、发布、核验成功后**自动清理，失败或同名文件已被替换时保留。原图仍可从 Git 历史找回。旧帖使用各自文件包里的图片，不依赖这里的文件。
