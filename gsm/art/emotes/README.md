# GSM 守宫表情包原稿

这套 25 张反应图采用用户批准的手绘守宫设计：黄色斑点身体、奶油色腹部、粗环纹尾巴和棕色轮廓。动作、眼神与道具分别表达每个反应；现有的 25 个语义 ID 保持稳定。

- `approved-preview.png`：用户批准的原设计预览。
- `atlas.png`：通过内置图像生成工具去除背景和标签后的透明原稿，1254 × 1254 像素。
- [prompts.json](prompts.json)：设计及透明原稿提取所使用的完整提示词。
- `export.mjs`：确定性裁切、平滑缩放和无损 WebP 导出脚本。
- `crops.json`：每张反应图在原稿中的精确裁切坐标。
- `preview.png`：由正式 WebP 合成的白底联系表，用于核对动作、裁切与透明边缘。

正式图片位于 `../../assets/emotes/gsm/`，均为 160 × 160 的透明无损 WebP。原稿按五行排列，列间距并非完全相等；最后一行另设边界，完整保留「溜了」左侧的速度线。每个裁切格等比缩放至最长边 140 像素，再居中放入画布，四周至少保留 10 像素全透明安全边距。

导出保留原稿透明度，只进行常规裁切、缩放和格式转换，不重新抠图、重绘或使用阈值清除低透明度像素。原稿背景中的极低透明度像素也随原稿保留。检查以正式白底联系表和掌机页面实际显示为准。

在仓库根目录安装现有工具依赖并导出：

```sh
npm ci --prefix gsm/tools/engine
node gsm/art/emotes/export.mjs
```

导出会覆盖 25 张 WebP、`manifest.json`、`crops.json` 和 `preview.png`，不会改动源图。脚本使用项目现有的 Sharp 依赖；相同依赖版本和源图会得到一致的 WebP 输出。源图、提示词及联系表用于维护，不会载入站点信息流。
