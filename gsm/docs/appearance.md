# 外观维护

外壳、天线、挂件使用同一套运行目录和本地测试页。正式入口为 `/gsm/`，设置入口为 `/gsm/settings/`；测试页位于 [`dev/appearance/`](../dev/appearance/index.html)，不随网站发布。

## 运行文件

| 位置 | 职责 |
| --- | --- |
| `device/catalog.mjs` | 外壳、天线和挂件的稳定 ID、三语名称及素材引用 |
| `device/stage.mjs` | 设备图层、屏幕、三枚原生导航链接与素材定位 |
| `device/device.css` | 设备比例、遮挡、接触阴影、镜片和背景 |
| `device/selection.mjs` | 默认组合、有效选项与保存选择 |
| `assets/device/` | 当前采用的透明 WebP 图片 |
| `dev/appearance/` | 直接使用正式页面的外观测试入口 |

首次打开使用豹纹奶油外壳、石墨短杆天线和绿色拼豆挂件。玩家在设置中手动选择后保存到 `umwelt-gsm-appearance`，刷新、跨页面和下次打开保留选择。链接中的 `shell`、`antenna`、`charm` 参数支持直接查看指定组合，也为存储不可用时的内部导航保留外观。

## 增加外壳、天线或挂件

1. 导出透明 WebP，检查实际文件大小、透明边缘和缩放后的细节。只将确定采用的文件放入 `assets/device/`，使用稳定的描述性文件名。
2. 在 `device/catalog.mjs` 相应列表登记稳定 ID、三语名称、图片和定位信息。设置页和测试页从同一目录生成选项，不另建页面。
3. 使用仓库根目录的本地服务打开 [appearance 测试页](http://127.0.0.1:8797/gsm/dev/appearance/)，检查新素材与已有外壳、天线和挂件组合。可切换「桌面 / 手机」预览，`?view=mobile` 直接打开 375×620 的手机视窗。预览选择不覆盖玩家的正式设置。
4. 核对屏幕和按键的定位、天线套口、挂绳穿环前后关系、挂件与壳体接触阴影，并检查窄屏和横屏下的操作。
5. 运行[检查说明](../tests/README.md)中的相关测试。替换素材时同步当前引用；确认没有使用者后删除不用的素材和制作过程，历史由 Git 保存。

## 图层与加载

屏幕、设置和信息流均使用原生文字与控件。三枚物理按键保留独立链接、可访问名称与键盘焦点。左下按键负责返回：个人主页和评论页回到来源位置，设置页回信息流，信息流回 Umwelt 主页。屏幕内不另设返回箭头。外观图层不得遮挡文字选择、点击或内部滚动。

按钮材质覆盖只显示指定键面，外壳原图和接缝保持连续。挂绳的返回段由当前外壳遮挡，阴影随挂件移动。共用天线使用统一接口；单个外壳的修正不得改变其他外壳的天线。

手机使用共同的紧凑视窗 `[32,24,960,1608]`（在含顶部天线空间的画布中）。原挂点与绳结保持定位，金属环和挂件本体从原图以 1:1 局部显示，放到机身上方；只替换中间绳段为盘绕形状。本体可轻度倾斜摆放，但不得缩小、镜像或倒置；桌面保持原摆放。

`mobileCord` 登记当前盘绳 WebP；`mobileFit` 登记原图裁片、位置、角度、绳结裁口和两端接点。坐标以挂件显示宽度 560 为准，`position` 是不含顶部留白的 stage 坐标，角度围绕裁片左上角。`cordSize` 与 `cordEnds` 对应盘绳图的显示尺寸和两个开口中心；渲染器将开口分别接到原绳结和原金属扣，不变形本体。新挂件需核对完整本体、前后遮挡、两端衔接和阴影范围。按钮反馈和接触阴影只绘制各自的局部区域，避免为小效果分配整张机身或挂件大小的滤镜图层。

手机触控区在键帽周围透明扩展，相邻按键不得重叠。滚动位置最多每秒保存一次，导航前即时保存；浏览器拒绝历史记录写入时仍须保持控件可用，并以原生链接完成跳转。

素材按当前组合加载；重复阴影和遮挡复用同一 URL，利用浏览器缓存。不要为了设置缩略图提前请求全部外壳，也不要把未使用原图或制作过程加入运行目录。截图、临时压缩对比和检查日志放在仓库外。
