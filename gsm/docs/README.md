# AI 更新入口

按本页完成爬爬在线的一次更新：理解已有世界和守宫，阅读现实材料，写出自然的发言，完成发布与线上核验。页面、资料或规则维护按当次请求处理。

启动语：

```text
读取 https://raw.githubusercontent.com/fivsevn/umwelt/main/gsm/docs/README.md 及其链接的写作与发布说明，按最新 main 完成一次爬爬在线更新并上线。
```

## 每次更新

1. **准备。** 核对最新 `main`，在仓库根目录执行：

   ```sh
   python3 gsm/tools/update.py prepare
   ```

   工具检查发布开关与账号权限，恢复唯一未完成的操作，输出工作文件位置。新操作均匀抽取1–10条新主帖上限，并从合资格的已有守宫中按活跃权重抽3位主动发帖候选。自然回复可使用其他合资格的已有守宫，每个串再独立抽取回复额度。用户明确指定总条数时才加 `--count N`（整数1–20），作为主帖与回复合计上限；恢复沿用原数量。具体命令见[执行与发布](publishing.md)。

2. **读完整资料。** 阅读工具生成的 `reading.md`：包含全体守宫档案、全部环境文档和已归档发言的原文，后续新增内容一并读取。按来源章节逐段读完，输出被截断时继续读取余文，核对材料路径与结尾，理清各自的生活、公开发言及知情范围。阅读量确实过大时，说明实际阅读范围，沿角色、事件和原串补读原文；摘要与索引保留回源位置。

3. **实际观察。** 从[世界趋势](../environment/world-trends.md)阅读正式资讯和社交话题，从[日常生活](../environment/everyday-life.md)阅读具体经历。每轮按[Meme 近期采样](../environment/meme.md#每次更新读取近期-meme)实际查看当期入口与近期原用法，按[评论区研究](../environment/comments.md)观察原串里怎样接话、互动怎样积累。每次实际读到至少3个原页、2个来源域名、1个带回复的讨论串、1条近7天材料，覆盖正式资讯、社交话题和日常经历三个类别；发布时观察记录保持48小时内有效。根据可读性、领域和已有事件轮换来源，将实际阅读范围填入操作文件。来源方式及改编见[写作说明](writing.md)。

4. **形成发言。** 结合守宫底色、当下情境与现实观察，选择随手想法、牢骚、展示、求助、跟风、闲聊或回复。先确定新主帖和要接续的旧串，按[逐串抽签](publishing.md#逐串抽取回复)取得回复额度，再沿完整原串安排多人交流。已有世界变化按实际影响接续，个人故事在合适时自然出现。主帖和回复合计，实际发言中至少一半由临时守宫路人写出，条数向上取整；例如5条至少3条使用 `guest`。完成数量可以低于额度，也可以为0。有正文时，按[评论与点赞](../environment/comments.md)审定基础点赞，按[配图](writing.md#配图)完成本次图片。

5. **审读并发布。** 正文为空时，按发布说明执行 `finish` 结束当前更新并报告原因。有正文时，按写作说明审读正文、点赞、实际图片与 `alt`，把采用的内容与观察填入同一份操作文件，导入归档，完成已采用持续变化的[资料回写](writing.md#资料回写)，再校验与构建。将帖子、配图、必要资料和生成数据放在同一个提交中，推送上线并核对实际内容。中断沿原操作接续，重写未完成导入前使用 `cancel`。

6. **报告。** 报告抽取上限、实际主帖与回复数、临时路人发言数、配图、资料变化和线上核验结果。

## 资料归属

[users](../users/README.md) 管个体，[environment](../environment/README.md) 管公共环境与交流研究，[writing.md](writing.md) 管创作，[publishing.md](publishing.md) 管操作。原帖保留具体经过。一项事实或规则只在负责位置维护，其他地方使用链接。

保留既有身份、头像和历史，网页沿用现有外壳、屏幕、布局与交互。其他游戏和共享视觉资料按各自维护规则处理；共用构建边界见[发布约定](../../docs/deployment.md)。旧研究与运营记录归入[历史资料](research/README.md)，不作为当前执行规则。
