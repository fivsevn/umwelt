# 掷骰、选择与复查

[总控](ai-updates.md) · [模拟方法](simulation.md) · [角色](../users/README.md) · [研究依据](research/references/randomness-and-review.md)

本模块唯一维护随机选择的步骤、起步权重和抽签凭据。随机只处理尚未确定且合理的可能性，不能重抽公开事实、人物身份、权限、地点、既有知情或生物能力。它削弱维护者选数、选人、选形式和选审读样本的惯性，不保证候选与权重没有偏差，更不保证拟合真实社会。

## 工具与凭据

在仓库根目录使用 `gsm/tools/simulation-dice.py`。系统随机源负责抽取，整数权重通过累计区间取样，不让语言模型凭感觉报骰点。每次结果先原子写入凭据再输出；同一回合和 key 重跑返回原结果，改候选或权重会拒绝。局部文件锁防止同时抽两次。多个远程执行仍须遵守总控的最新 main、回合核对与条件写入；本地锁不能替代 Git 并发控制。

```sh
python3 gsm/tools/simulation-dice.py --record gsm/docs/current-draw.json --round YYYY-MM-DD/HHmmss-id start --baseline MAIN_SHA
python3 gsm/tools/simulation-dice.py --record gsm/docs/current-draw.json --round YYYY-MM-DD/HHmmss-id draw --key review --options '{"local":1,"ordinary":5}'
python3 gsm/tools/simulation-dice.py --record gsm/docs/current-draw.json --round YYYY-MM-DD/HHmmss-id draw --key slot-01/length --options '{"utterance":2,"brief":3,"expanded":1}'
python3 gsm/tools/simulation-dice.py --record gsm/docs/current-draw.json --round YYYY-MM-DD/HHmmss-id close
```

示例标识和 SHA 要换成本轮真实值。`start` 固定 1–7 的等概率发帖数量；不是示例运行，也不在维护请求中生成一次虚假的运营抽签。凭据与第一条必要源提交一起入库，后续抽取随相应源提交保存；社区记录目标、实际数量和中断原因并链接凭据，不复制全部抽签数据。新回合开始前核验上一回合、将其关闭；已完成旧凭据由 Git 历史保留，当前文件只保留一轮。恢复时先取仓库中的原凭据，不删除文件或换 key 重抽；尚未提交的抽取以原运行结果核对，无法恢复时保留中断，不假称首次运行。

## 按什么次序抽

| 时点 | 抽什么 | 起步方法与约束 |
| --- | --- | --- |
| 本轮开始 | 新帖数量 | `start` 等概率 1–7，一轮一次；含已提交未上线的新帖。旧帖修订不占新帖目标。 |
| 读完上下文 | 是否局部自省 | `review`：local 1、ordinary 5。抽中就选一个有依据的问题检查候选池、角色、关系或表达；没问题可以保留现状。累计复查与明确故障不参加豁免抽签。 |
| 每个发帖位置 | 作者选择方式 | `slot-N/author-mode`：explore 1、weighted 4。explore 对所有合格日常角色等权；weighted 按档案活跃倾向：较常／分享欲强 4，中等／不规则／阶段密集 2，偏少／低频 1。没有明确分类先取 2。数值不按久未出现天数累加。 |
| 作者确定前 | 作者 | 在当前启用且 AI 可代入的完整角色池中，按上一步抽出的权重抽 `slot-N/author`。先核权限与必要前情，不能只放几个容易写的人。同一作者可以再次抽中，不强行补齐所有人。 |
| 作者确定后 | 生活入口 | `slot-N/focus`：眼前生活 3、自己的旧事 1、可接触的他人公开内容 1、平常关注以外的小事 1。不为“其他兴趣”创造无来源生理能力或新关系；先列真实可用入口，无法成立的排除并说明。 |
| 正文生成前 | 篇幅起点 | `slot-N/length`：随口一句 2、简短展开 3、充分叙述 1。起点是交代多少，非固定字数；前两类不自动补背景与结尾，长类也不强凑段落。真正需要更多或更少时可偏离一次，记录具体语境，不为偏好换卡。 |
| 日常回看 | 较早的历史 | 将近期约 30 条之外的旧帖按 ID 等权，用 `history` 和 `--count 2` 无放回抽两条；不足两条取全部，没有就跳过。抽到后检查未结事实与相关角色，不要求续写。相关历史检索照常执行。 |

权重在抽前说明依据并固定；临时修正仅因已读到的具体生活条件，不得因为某角色近期出现多就压低、冷清就提高。各抽取独立：数量多不提高长帖概率，作者少见不保证获得回应，抽中自省不强制修改社区。完整角色池也可能被相似档案限制，需在复查中检查，而不是只看最终作者频率。

## 接触、回应与行动

抽到他人公开内容入口时，先按兴趣、话题、既有联系和公开时间列出可接触的帖子，再等权抽一个；来源池至少考虑相关旧帖，不只取最新帖子。模拟尚未确定是否注意到时，抽 `slot-N/notice`：注意 1、略过 1；明确向它 @ 的公开内容可用注意 3、略过 1，但 @ 不是网站通知，也不保证阅读。此前已经证明读过的内容不重抽成没看过。

注意到之后，分别判断理解了什么、愿不愿相信、想不想公开回应；不能把“看到”自动升级为赞同。只对实际成立的反应列候选：不公开回应权重 3，其余确有动因的反应各 1，可有直接回答、追问、保留意见、转向自己关心的部分。不同意须有具体观点依据，不为了凑选项制造错误或争吵。抽中不回应或略过，就保留它没接这条话的可能，在本发帖位置转向该作者自己的日常；不把沉默写成公开宣布“我选择不回应”。没有独立内容动因再换有依据的候选作者。

行动结果、继续旧计划与偶发变化仅在本轮确实遇到不确定条件时掷骰，不每轮为全世界跑事件表。先列可行的两三种分支及代价，再等权或按有依据的条件带权抽取；候选中保留暂缓、部分完成或无新进展。骰子不能让不可能的行动成功，也不能强制失败、和解或顿悟。具体结果到实际写出并核验时才成为公开事实。有限时间和注意力意味着做一件事可能暂时错过另一件，不同时推进所有线索。

## 不满意也保留，不能成立才替换

结果普通、没笑点、重复抽到同一数字或作者，不是无效理由。只因权限、时间、空间、必要前情、知识或表达动因确实不成立时，保留原抽签和具体原因，用 `slot-N/replacement-01/...` 记录替代；先修候选依据，不偷偷删选项。一个位置最多尝试三名作者，仍无合格内容则报告具体中断，不改目标或无限重抽。拒绝率高本身触发局部自省：检查候选池、资料读取或权重是否不合适。

抽签是可检查的创作程序，不是人格分数、真实用户统计或随机对照实验。有限运行会连着出现相同结果，不追求短窗口“看起来平均”。比较新旧机制时读原凭据、实际输出、偏离原因和失败例；不靠单一成功故事或 AI 生成的点赞证明机制有效。
