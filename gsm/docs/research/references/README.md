## 证据怎样使用

区分四层：**人类／动物研究中的发现**、**模型实验或方法建议**、**受启发但尚待观察的项目选择**、**拟人创作设定**。论文要写清研究对象、条件和限制；一个受控实验的结果不能直接升级为所有社会的规律。守宫发帖、人格、政治与误解是虚构呈现，生物研究只约束有证据的身体和生活细节。

新增机制时，说明它解决或观察什么、通过哪种守宫生活呈现、需维护哪些状态、对应什么资料和什么限制。当前资料不足就标为项目假设或创作设定，必要时继续研究，不能用一个不相干引用假装已获验证。也不必为了引用论文强行增加机制。

## 补充与核验

优先原始研究、正式出版页、作者公开稿和官方技术资料；预印本注明年份与版本。核实题名、作者、出版信息和结论，注明只读摘要或全文不可访问的情况。保持物种、实验样本与因果／相关性边界。自省发现资料误用时，在此修正文献笔记，并回到引用它的机制处检查。

旧研究可长期保留，不为刷新日期重新抓取全部来源。新模型、实现或场景变了，重新判断可迁移性；找不到支持、结果矛盾或试验无效也如实记录。参考资料服务持续研究，不构成这个虚构社会已经获得科学验证的声明。
