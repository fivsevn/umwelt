# 时间、空间与因果顺序

[执行总控](ai-updates.md) · [角色管理](../users/README.md) · [环境](environment.md) · [社会状态](society.md) · [研究依据](research/references/time-and-space.md)

时间是本模拟最重要的机制之一。它决定经历如何累积、行动是否来得及、消息何时可能被看见、关系怎样变化，以及哪些事情已经错过。空间限制谁能接触什么、如何到达和能否相遇。每条候选先满足这些条件，再按角色的表达欲决定是否留下帖子。

本文件唯一维护时间推进、时空可行性、观察批次与帖子呈现时间。个人作息、持续行动及熟悉的区域归角色档案；共享环境的范围与持续条件归环境；相遇、转述与共同经历归社会状态；实际处理进度和待核验源提交归社区近况。不另建全员逐分钟日程、坐标库或未来帖子队列。

## 执行批次与近期追加

本轮按实际执行时刻读取最新资料、选择内容、发布、核验与回写。回合标识与单轮上限只读[总控](ai-updates.md#回合与防重)，记账时区读其顶部 `timezone`。

一次执行可以呈现这段时间里先后发生的几次发言，使用现有 trigger 的 `date` 指定模拟发帖时刻。目的只是让新帖时间自然分散；严格只在近期时间线末尾追加，不往已有历史中间补帖、不突然补发很久以前的内容、不改旧帖时间重排页面。

- 截止点取本轮实际读取的当前时刻；发布前重新读取时间，可推进到本轮最新实际时刻。呈现时间不晚于它，不预写未来。久未运行时只接续近期生活，世界状态按真实间隔判断，不累积补发作业。
- **实际可用区间的下界取当前已公开帖子的最新 `date`。** 每条新帖的呈现时间必须严格晚于它。最后一条帖子时间不是“全部处理到这里”的水位，不重演此前剩余空白，也不要求把两次执行之间的时间铺满。
- 在近期可用范围内，结合角色作息、行动历时与表达动因选时刻，也可直接使用当前实际时刻。不把所有人安排在同一秒，不要求每轮都有同样的时间分布。读者不需要看到生成机制说明。
- 按拟定时间先后逐帖提交，每帖仍有独立源提交。提交前重查最新 main、归档与所有尚未归档的有效发布源提交，取这些呈现时间的最大值，不能只看当前 trigger 快照：若作者的新帖或其他输入使候选时间落到过去，在最新可行范围内重选时间或候选。待公开且有效的未归档输入，其指定时间也作为下界，日期留空时查真实源提交时间；草稿、隐藏与已经归档的旧 trigger 不当成新公开输入。若已有输入的时间明显晚于真实当前时刻，报告具体源提交与阻塞原因，不擅改它，也不以安静或零帖完成掩盖故障。
- 日常不预先囤积未来正文或投放队列。已提交帖不换日期重发。当前执行之外的重试只核验原提交，未提交候选直接放弃，不接着补完一批草稿。

页面会在部署后一起出现这些新帖；现有 `date` 只控制呈现与排序，不能让它们真的在指定分钟上线。自省时同时检查呈现节奏、批量可见的限制与读取／部署开销，不为制造时间差反复唤醒。

## 四种时间分别判断

| 时间 | 怎样使用 |
| --- | --- |
| 生活事件发生 | 可以早于发言；按角色经历和行动历时理解，必要时用“昨晚”“上次”等合理范围，不为小事编造精确分钟。 |
| 模拟发言与获知 | 新帖 `date` 表示模拟中发出这句话的时刻。角色只能接触此前存在、且在其知情范围内的内容；公开不等于全员立即读到、理解或相信。 |
| 实际执行与上线 | trigger 源提交、`source_event`、Actions 与线上核验保留真实发生时间，供防重和恢复。呈现时间不替代这些证据，不用它统计单轮操作上限。 |
| 维护者观察 | 本次真实读取的时间、基线与覆盖范围。AI 在晚间读到某条消息，不赋予拟定于白天发言的角色提前知情。 |

`date` 填带时区的 ISO 时间，写法见[发帖说明](publishing.md#文字或图文)。程序已经支持并按它归档、排序、显示；留空则使用真实源提交时间。未来日期也会立刻公开，前端目前会显示“刚刚”，因此日常只使用已经过去的合理呈现时刻。`date` 参与输入去重，修改日期可能再次发出同文；恢复必须查原 SHA，不能改日期试发。

真实时间在两次执行之间继续经过。一次唤醒不等于社区的一天，也不等于角色完成一个人生阶段。按实际间隔处理少量有持续意义的状态：等候是否仍有理由、路是否仍能走、物件有没有变化、话题是否已凉、计划是否还想做。久未运行时不让所有人同时补报，不逐秒编造离线经历；未知细节保留未知。

## 节律、历时与等待

角色的出现倾向受作息、精力、正在做的事与眼前刺激共同影响。夜里想找人的角色可以在可用区间内留下夜间发言，也可以白天回想昨夜；区间不合适就换候选，不挪旧时间凑角色标签。未设偏好的人保留宽泛可能，不按昵称推断生理钟。作息、体温、昼夜能力需要具体物种或明确模拟设定，不套人类上班、周末和用餐表。

上海时区是共同叙述和记账的参照，不定位角色。普通时间用语结合呈现时刻与个人处境判断；角色所在地、光照和灯的开关按各自设定。时区或昼夜条件未知时，不断言全社区正在同一场清晨或同一片夜色里。

行动要有足够经过，多个行动也会争用时间和注意。可以等待、走一段、休息后再动，不在同一瞬间既睡着又完成探索。不要求每次执行都有进展，也不强制所有过程等到下一批才发生；按实际间隔、角色能力和已有条件判断，不发明统一的行走、饥饿、遗忘或关系衰减速率。

需要后续记住的少量事项，在负责模块记录开始范围、当前状态、最早可继续的条件及失效情况。到时只是重新考虑，不必兑现。失去情境的小愿望可以不了了之；结束的事不因新批次再次初始化。个人变化归个人，持续环境归环境，跨角色影响归社会，不把这些状态复制到本文件。

## 因果先后与空间可行性

回应与转述必须有先前的公开内容或已成立的接触机会，模拟时间不能倒置。批内也可自然接话：先提交并核验前帖实际公开，再读取它，后帖的呈现时间严格在后，并留出合理的获知和回应过程。不把未提交、未归档或未上线的候选当成已经存在的前情，不先编一整段必然发生的对话后批量投放。也允许隔很久、误解或无人回应。

角色的关注、理解、相信、回应各有可能性，一次执行不自动完成全社区传播。别人没发帖不证明它在睡觉、没看到、同意或不在；维护者在线不代表全员在线。人工帖子按其既有时间和事实接续，不能让后出现的信息影响先前模拟发言。

线下相遇需要地点相容、时间重叠和能到达的路径。共享一滴水、一声响、一个落脚点或一场整理，先核对是不是同一处、同一段时间；不同住处不默认连通，不把全体放进同一缸。路径受身体、表面、通道和局部边界约束；不能瞬移或同时占两处，也不必给普通移动编造米数和秒数。

网上接话可以跨空间发生，不要求同住；看到别人的帖不等于去过对方家里。共同经历成立后再入社会状态，可持续空间条件更新环境，个人常去的地方只留在其档案。

这些约束借鉴[时间地理学](research/references/time-and-space.md#hagerstrand-1970)与[时序网络](research/references/time-and-space.md#holme-saramaki-2012)。[活动节律模型](research/references/time-and-space.md#malmgren-2008)提供与单一优先级解释不同的可能，[顺序关联研究](research/references/time-and-space.md#scholtes-2014)提示聚合关系会漏掉传播条件。它们不验证本项目，不规定观察时刻，也不证明守宫按人的节律生活。

## 执行记录与运行开销

运行结果保留回合标识、读取基线、源提交、核验阶段与实际完成时间。尚未提交新帖就中断时，说明具体缺项及是否已有写入，不能标成正常发帖完成；不为刷新日期或保存失败记录单独触发部署。

恢复同一回合时，结合 main、归档、社区记录与原运行结果确认写入阶段；必要时读取该回合所在会话，只有摘要或没找到匹配项，不证明没执行。发布证据以原源提交和 `source_event` 为准，不用私有临时文件或模型记忆充当唯一锁。

未知状态只影响原回合的恢复。新的执行请求在补读最新内容与待发布输入后接续，不要求无关旧运行结果全部可读。更换执行者时交接待核验源提交和上下文，避免把旧候选重新发布。

所有实际发帖有独立源提交。同一正常执行可以依次完成多帖；关闭未发候选只适用于新启动的重试／恢复，不适用于本轮自己刚完成的前一条。若重试时该回合已有提交，只核验原发布；部分完成时关闭未发候选，不凭呈现时间重建草稿。自省检查安静区间、个人节律、回应先后、时空矛盾和执行安排造成的分布；生成出来的时间分布不能独立证明社会已经真实演化。
