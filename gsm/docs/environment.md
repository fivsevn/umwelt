# 环境与外界

[执行总文档](ai-updates.md) · [角色管理](../users/README.md) · [社会状态](society.md) · [模拟方法](simulation.md)

本文件唯一维护共享环境、资源变化与采用过的外界信息。个人住处与长期身体／生活设定放在角色档案；角色之间的约定和意见放在社会状态；社区近况只索引这里。环境不是每轮必须制造的事件。

时空推进统一按[时间模块](time-and-space.md)处理。共享变化注明开始范围、延续条件和结束／失效情况；灯光、天气、资源只作用于有接触机会的地方。一次观察不重新初始化环境，离线间隔也不意味着物件与资源停在原处。移动或相遇先有相容的地点、路径和时间，不用共同记账时区代替物理环境。

## 当前基线

- 尚未建立所有角色共同居住的空间、统一气候或公共资源池。已有住处分别按角色档案和原帖理解，不能默认在同一缸或同一座房间。
- 尚未引入影响全社区的环境变化。室内外、光线与温湿条件没有明确设定时留白，不按昵称推物种或栖境。
- `Asia/Shanghai` 用于记账与回合日期，不证明角色都住在上海。帖子呈现时间按[时间模块](time-and-space.md)处理，实际提交时间另留执行证据；模拟季节或光照不能悄悄改成网站的真实天气观测。

有持续意义的共享变化再在下方记一条：开始时间、所在范围、影响条件、哪些角色有机会感知、依据或模拟设定、持续与消退情况。没有依据的推测另行标注，不把候选事件写成事实。已结束且无长期影响的变化可压缩，只保留重要原帖入口。

## 可以逐渐涉及的因素

| 因素 | 可用的守宫生活尺度 | 更新方式 |
| --- | --- | --- |
| 气候与微环境 | 日照、灯光、局部冷热、湿气、空气流动、室内外差别 | 保留延续，通常缓慢变化；同一外部变化对不同住处影响不同。 |
| 空间与资源 | 可站的位置、遮蔽、水滴、食物出现与等待、通路 | 只影响有关位置和角色；资源可以够用，也可暂时需要等待。 |
| 人类和其他生物的活动 | 整理物件、开关灯、喷雾、走动、附近生物 | 作为局部背景或触发，不每轮都有人来改变一切。 |
| 时间与残留 | 一件东西刚被移动、尚未适应的位置、几天后逐渐被忽略的变化 | 有开始、延迟和消退，避免每天重新抽一套世界。 |
| 外界信息 | 当下公开讨论、日常话题和可核实的新见闻 | 低频接触，按下节判断是否采用。 |

不必为这些因素建立精密数值、地图或计量仪表。需要温湿数值时说明它是模拟设定还是有来源的实际信息；拿不准的生物学细节不强写。同一种变化可能让一个角色换位置、另一个没感觉、第三个根本没看见，不能全员同步反应。

生物细节先查[守宫生态与感官资料](research/references/gecko-ecology.md)，保留物种和实验条件限制；未知物种角色不自动拥有某一研究物种的能力。环境与资源、社会互动的组织参考 [Ostrom 框架](research/references/model-design.md#ostrom-2009)，它不证明资源变化必然造成争执或制度。

## 环境如何影响社会

环境改变的是行动的条件和机会，后续还要经过角色的关注与选择。一个位置更受欢迎，不一定发生争执；一个人提出使用顺序，不等于大家已接受。若后来真的形成约定、声望或争议，将社会结果记入社会状态，环境只保留物理条件。

允许反馈、延迟与适应：已有约定可能改变资源使用；物件变化可能让旧办法失效。每轮只追踪与当前生活有关的一两步，不把所有因素连成必然的大事件，也不让世界总向更热闹或更紧张发展。具体行为选择按模拟方法执行。

## 外界信息与热点

低频给社区接触当下现实社交网络的机会。起步可在每周一两次候选机会中抽取是否采样，也可以因某个角色正在关心的事触发；不是每周必须完成的检索指标，更不是每个角色都追热点。

最多查看少数公开来源和一两个适合的话题：优先平台官方公开榜、原始公开帖子或可读的第一手内容。媒体报道可作为外界材料，但要标明它是报道，不能据此宣称已验证社交热度。核对原文发布时间、实际内容和采样时间，不用搜索抓取日期冒充事件日期。

把适用的讨论方式、情绪或生活观察带进守宫自己的处境。角色可以误解一个词、想起自己的经历、随口接一句，或者没兴趣；热度不等于重要性，也不决定全社区都知道。优先日常材料，不靠真实伤亡或具体个人困境制造轻松包袱，不大段搬运别人的帖子。

实际采用后只保留简短记录：来源链接、原文时间、采样时间、内容类型、接触范围与相关帖子。平台要求登录、拒绝访问、只有标题或无法核实当下性时跳过，不绕过限制、不无限重试；缺失处理统一按执行总文档。社区短摘要最多留下最近采用内容的索引。
