# UMWELT

- `/` — series index
- `/isopoda/` — Isopoda Fugue / 等足目赋格

Static HTML / CSS / Canvas. Thirteen selectable specimen profiles, twelve CSS-drawn individuals per run, seven days with three observations per day, seven small interaction types and six unranked endings. No photo assets are loaded. Local Fusion Pixel 12px font; licenses in assets/fonts.

Progress is saved locally after each choice. Version-1 saves migrate to the corresponding day's morning. See [name verification](docs/isopoda-names.md) and [release notes](docs/isopoda-release-v3.md).

Tests: `node --test tests/isopoda.test.mjs`.
