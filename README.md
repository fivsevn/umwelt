# UMWELT

- `/` — series index
- `/isopoda/` — Isopoda Fugue / 等足目赋格

Static HTML / CSS / Canvas. Thirteen selectable specimen profiles, twelve CSS-drawn individuals per run, seven days with three observations per day, seven small interaction types and six unranked endings. No photo assets are loaded. Local Fusion Pixel 12px font; licenses in assets/fonts.

Progress is saved locally after each choice. Version-1 saves migrate to the corresponding day's morning. The current data and renderer follow the two author-supplied Draft v1.0 standards. See [migration report](docs/isopoda-morphology-v4.md). Old v3 naming notes are historical, not current evidence.

Tests: `node --test tests/*.test.mjs`.
