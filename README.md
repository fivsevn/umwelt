# UMWELT

[开发与维护文档](isopoda/docs/README.md)

**UMWELT** 是由 **fivsevn** 发起并维护的个人实验项目。

项目名称借用了德国生物学家 **Jakob von Uexküll（雅各布·冯·于克斯屈尔）** 在动物知觉与行为研究中发展的 **Umwelt** 概念。不同生物并非只是处于同一个抽象的“环境”之中，而是依据自身的感知与行动方式，生活在各自具有意义的周遭世界中。本项目借用这一概念作为名称与思想来源，具体内容、视觉设计、交互方式与实现均属于项目自身。

项目主页：

https://umwelt.fivsevn.com

## Isopoda Fugue / 等足目赋格

《等足目赋格》是一项以等足类动物为主要对象的浏览器交互作品。项目参考生物学、自然史及人工饲养相关资料，并将其中部分内容转化为视觉与交互表达。

作品中的表现形式、参数与交互逻辑属于创作性处理，不构成对真实生物学现象的完整复现。

## 资料来源与内容边界

UMWELT 涉及真实动物、分类学、形态学、自然史、生态环境、人工饲养、人工培养品系及贸易名称等内容时，会尽可能依据可以识别和核查的实际资料，并区分资料事实、研究参考、工作性判断、视觉表现以及作品内部的模拟参数。

项目可能参考的资料包括但不限于：

- 学术论文与专著；
- 分类学数据库及生物多样性数据库；
- 博物馆、大学、研究机构及专业组织公开资料；
- 自然史记录与物种描述；
- 人工饲养记录及长期观察资料；
- 培养品系、贸易名称及相关流通资料；
- 公开可访问的图片、视频及其他视觉参考；
- 其他能够明确识别来源的外部资料。

不同来源的可靠程度、研究目的和适用范围并不相同。项目在整理资料时会尽可能进行交叉核对，但引用某项资料并不代表对该来源全部内容的认可，也不代表相关信息不存在后续修订、分类变更或学术争议。

对于分类学名称、物种身份、地理分布、形态特征及其他可能随研究进展发生变化的内容，应以相关领域最新的专业研究和权威数据库为最终参考。


### 事实资料与创作内容

项目会尽可能区分以下不同性质的内容：

- **资料事实**：具有论文、数据库、正式记录或其他可核查来源支持的信息；
- **研究与视觉参考**：用于理解真实生物或辅助视觉设计的资料；
- **贸易与培养信息**：人工培养品系、贸易名称或市场中使用的工作性名称；
- **工作性判断**：在资料不足时，为整理、制作或研究所作的暂时判断；
- **视觉参数**：为程序绘制、比例统一或视觉识别而设置的表现参数；
- **交互参数**：为作品运行、节奏与交互逻辑而设置的参数；
- **创作内容**：明确属于虚构、设计或艺术表现的部分。

上述类别之间不应相互替代。

视觉表现参数不能直接视为形态学测量数据，交互参数不能直接视为动物行为实验结果，培养或贸易名称也不能自动视为正式分类学名称。


### 模拟参数

项目中的温度、湿度、移动速度、成长比例、活动状态、行为概率、环境变化及其他类似数值，可能根据作品表现、交互节奏或技术实现进行简化和调整。

这些数值不应被理解为：

- 精确的生物学测量结果；
- 实验数据；
- 对自然环境的完整模拟；
- 对特定物种行为的确定性描述；
- 动物饲养标准；
- 专业的饲养、兽医或生态建议。

如果需要进行真实动物饲养、繁殖、运输、研究或其他实际操作，应另外参考可靠的专业资料，并根据具体物种、环境和个体状况作出判断。


### 外部资料

项目中引用、链接或参考的论文、数据库、网站、图片、视频、自然史资料、贸易资料及其他外部信息，仅用于研究、事实核查、视觉参考或创作辅助。
