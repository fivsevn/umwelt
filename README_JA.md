# UMWELT

[中文](README.md) | [English](README_EN.md) | **日本語**

**UMWELT** は、**fivsevn** が立ち上げ、維持している個人実験プロジェクトです。

プロジェクト名は、ドイツの生物学者 **Jakob von Uexküll（ヤーコプ・フォン・ユクスキュル）** が動物の知覚と行動の研究において展開した **Umwelt（環世界）** の概念に由来します。異なる生物は、単に同一の抽象的な「環境」の中に存在するのではなく、それぞれ固有の知覚と行為のあり方を通して、自らにとって意味をもつ周囲世界を生きています。本プロジェクトはこの概念を名称および思想上の出発点として借用していますが、具体的な内容、視覚設計、インタラクション、実装は本プロジェクト独自のものです。

プロジェクト公式サイト：

https://umwelt.fivsevn.com

### 事実資料と創作内容

本プロジェクトでは、可能な限り以下の性質の異なる内容を区別します。

- **確認可能な事実**：論文、データベース、正式記録、その他の検証可能な出典に基づく情報；
- **研究・視覚資料**：実在生物の理解や視覚設計の補助に用いる資料；
- **流通・飼育系統情報**：累代飼育系統、流通名、市場で用いられる暫定的・実務的名称；
- **暫定的判断**：資料が不足している場合に、整理、制作、研究のために行う一時的な判断；
- **視覚パラメータ**：プログラム描画、比率統一、視覚識別のために設定された表現上の値；
- **インタラクション・パラメータ**：作品の動作、テンポ、インタラクション設計のために設定された値；
- **創作内容**：明確にフィクション、デザイン、芸術表現として扱われる部分。

これらの区分は相互に代替されるものではありません。

視覚表現上のパラメータを形態学的測定値として扱うことはできず、インタラクション・パラメータを動物行動実験の結果として扱うこともできません。また、飼育系統名や流通名が自動的に正式な分類学名となるわけではありません。
