# 空天台与郭里园街区模型（本地审核）

本页是背景第一版的历史制作记录，保留当时的布局、尺寸、图集和本地审核事实。当前入口、源稿与发布状态见 [花农时代维护索引](../../rooftop-README.md)，现行唯一测试页见 [综合场景测试](../../rooftop-scene-review.md)。当前建筑源稿使用 [rooftop-weathering-07](../rooftop-weathering-07/README.md) 的 `game-environment.blend`、`terrace-book.pxo` 及 1024×1024、16 像素/米图集；下文第一版原稿及规格不覆盖后续修订。

本轮重建本楼、北天台、南阳台和周边街区。天台上的家具、植物盆器及其他陈列暂时移开；东东和小猪隐藏，动作系统继续运行。植物、日本古董、枪械和手帐资料，以及天气、季节、时间与原存档保留。

## 本地查看

在仓库根目录启动静态服务器，打开：

`http://127.0.0.1:4173/rooftop/?stage=background&weather=overcast&time=day&season=autumn&scene=north`

审核界面提供南北切换、楼排概览、天台远眺、手帐和天气、时刻、季节选择。拖动及方向键可以转动观察。`stage=background` 使用独立的审核布局和天气会话键，车库里的试摆不会清空正式存档。本轮没有推送、部署或上线。

上述会话陈列与未上线说明属于第一版制作时的状态。2026-10-11 统一入口后，测试观察页永久保持空场景，不读取或写回布局存档；物品与原存档仍在独立车库使用。后续发布结果以当前维护索引和对应部署记录为准。

## 建筑与地图依据

本楼位于楼排中间，左右均有邻户。六户组成三对相邻露台，每两户之间相邻，每对之间有十二个游戏单位的退台间隔；同样的凸出部分延续到邻户和下部楼层。间隔底部保留两间并排小车库，本楼下面没有商铺。

地坪至六楼檐口为 5.6 个游戏单位，屋脊为 13.2 个单位；靠屋顶一侧保留完整六楼墙面、小窗和门凹口。南北地面分别绘制灰浆补块、细裂缝、被擦弱的接缝与旧混凝土色差。

南面最近的邻楼直接复用本楼原生模型，保留成对露台、凸出部分和完整六楼；北面的最近邻楼按照片制作封闭阳台、白色小砖雨篷、窗框、晾晒架、防盗栏、空调风扇和排水管。每栋都有真实的两端和侧墙。

2026-10-11 再次打开 Google Maps 航拍，修正了原先自行补出的垂直侧楼和环绕高楼。`map-layout.json` 保存航拍屋顶位置记录、取景中心和转换比例。近处楼排采用相同方向平行排列；街区外层老楼和北侧高层住宅也从航拍中的楼群位置转换而来。道路、停车与绿化位于楼排间和公共道路旁。相邻楼排的商铺使用地图可见名称；地图商铺标签不能证明本楼有底商，因此本楼没有附着任何店面。

航拍可确认屋顶轮廓、朝向、相对位置和道路关系；照片补充外墙与窗、阳台细节。这里没有到户实测尺寸，高楼层数也根据照片作近似。它是一份可继续核对和调整的源模型，不能当作测绘成果。数据中记录的屏幕取点用于复查布局；后续修改应更新对应记录，不再用随机楼群补背景。

## 原生源文件与复用

- `empty-rooftop.blend`：实际 Blender 4.5.14 LTS 原稿，保留全部可编辑网格，打包实际 Pixelorama 贴图。本楼、用户天台、邻户天台、北侧老楼、南侧同型住宅、外层老楼、远处高楼、街道、绿化、车辆和商铺分组保存。
- `terrace-book.pxo`：实际 Pixelorama 1.2.3 的 512×512 原稿，通过原生 1px Pencil 和 Text 工具绘制。南北地面各自具有整块画面；旧粉刷、黑灰瓦、红瓦、锈铁、玻璃、车身、车库卷帘与店招各有独立材质区域。
- 车辆原稿有独立的轿车、两厢车和小面包车素材集合，底部以零高度为基准；原稿模板隐藏，街上的停车是实际原生网格副本。车轮、空调风扇、树冠和自行车轮均为真实几何。
- 可通过 Blender 的 Append/Link 复用整个集合；源集合带有素材标记。楼栋使用原生集合实例，修改楼型源集合即可同步各处；也可以 Make Instances Real 后单独编辑。单位沿用游戏世界单位，复用前按所需比例缩放。Blender 坐标 `(x,-z,height)` 对应游戏 `(x,height,z)`。
- `build-shell.py`、`mapped-neighborhood.py`、`street-life.py` 保存本版建模流程；后续可以直接手改 Blend。`revise-map-layout.py -- --apply-map-revision` 会重做周边楼群，保留本楼原稿；运行前须保留人工改动。`append-street-life.py -- --replay-street-life` 只重做街道生活部分。
- `author-textures.py --replay-existing` 通过实际 Pixelorama 重放绘画。已有 PXO 时默认禁止覆盖；直接手改 PXO 后需重新导出 PNG 和网格描述。

## 浏览器资源与核验

`rooftop/assets/background/` 包含从保存的原生网格直接导出的 `.bin`、`.mjs` 描述和 PNG，没有另一套在浏览器里重写建筑的建模程序。重复立方构件按材质合并为实例，其他实际网格合并导出；资源地址带有导出内容的指纹。原稿、制作过程和地图记录不进入网站发布包。静态资源可继续用于 GitHub Pages。

当前网格二进制为 3,762,944 字节，贴图为 38,321 字节，共 44 个绘制分组。共享原生集合的局部构件变换和楼栋变换，浏览器仅在加载时组合，避免每栋重复下载同样的门窗数据。原生可编辑模型为 7,816,110 字节；实际源稿含 31,622 个网格对象，集合实例组成完整街区。`reexport-native.py` 只重新打开并导出保存的原稿，不重做几何。

`blender-source-check.json` 记录 Blender 重新打开后的网格、贴图和集合核验；`pixelorama-source-check.json` 记录 PXO 实际图层像素与导出 PNG 的逐像素一致性。测试另外检查南北可行走地坪坐标、每户凸出部分、车库间隔、楼群相互不交叉、楼排朝向与本楼无店招。

保存中的南北局部坐标及原放置规则不变。正式陈列仍为北天台 86 件、南阳台 20 件、房间 19 件；背景审核入口只把前两处显示为空。确认背景后再重新设计家具。
