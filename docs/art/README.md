- [蜱虫视觉指南](../../tick/docs/maintenance.md)：交互绘制与视觉参考。

原稿、来源记录与检查结果各有用途。先保留手工编辑，再修改、导出和核对；临时截图与日志写入仓库外。检查记录只对应当次运行，不能替代后续改动的验证。

原体温调节模型、像素对照地址保留转向页，实际预览在游戏的原稿目录中维护。
