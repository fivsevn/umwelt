# 世界空间空气与天气

建筑、物品、人物、光影、季节粒子和雨共用[最终低采样](../../../rooftop/docs/pixel-style.md)。运行契约见[维护入口](../../../rooftop/docs/maintenance.md)。

- 柳絮、雪、叶屑和雨使用真实世界空间，保留稳定身份、重力、风、远近、建筑遮挡及视差。镜头变化只选择需要运行的空气单元。
- 完整效果覆盖小鸟、无人机、邻居三个实际游戏视角，包含移动和变倍；邻居按有效圆形镜片分配。额外天台、楼排、远处测试取景维持局部效果。
- 固定池上限为春 16、夏 20、秋 64、冬 112、雨 840，提交活动可见部分。边缘留余量并渐隐，夏季虫点保持露台低位。
- 天气菜单与自动池为八种，阴天规范值为 `overcast`，兼容旧 `cloudy` 链接与保存值。
- 公开游戏读取完整陈列并显示东东与小猪；统一测试的场景组清空物件并隐藏角色，初始组合组使用固定陈列并显示角色。测试三组均使用独立数据，个人存档保持不变。

修改后检查南北三个游戏视角、宽窄画面、四季与降雨、镜片、连续运动和世界遮挡；减少动态设置仍保留必要运动。自动检查见 `rooftop-visible-air`、`rooftop-seasonal-coverage`、`rooftop-outdoor-raster` 及 `rooftop-render-budget` 测试；实际浏览器与最终发布包另行核对。
