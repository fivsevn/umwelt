# 三种游戏视角的空间天气与统一采样

2026-10-12。本轮沿用已认可的 [02 Blender／Pixelorama 原稿](../rooftop-lowpoly-02/README.md)与约 2.5 CSS 像素的最终画面格。建筑模型、UV、家具原稿和放置规则不改。用户已授权本轮直接发布；发布结果在本记录的末尾核验后补入。

## 制作规则

继续从完整的 Blender 模型制作，保持像素画风及真实的厚度、背面、底面、支撑、连接和承放结构。Pixelorama 负责统一物理像素格的材料与旧化。家具不为画面粗糙而额外删结构。原稿质量、原生材料格、最终屏幕格分别验收；游戏用共享低分辨率采样形成粗颗粒，不能单独扩大家具的像素块。规范入口为 [美术管线](../../rooftop-pixel-style.md)与[游戏文档入口](../../rooftop-README.md)，下一轮家具重制继续读取这两处。

户外目标为 2.5 CSS 像素，设备像素格为 `round(2.5 × devicePixelRatio)`；当前 DPR 2 是完整 5×5 格。建筑、阴影、季节粒子、雨丝和瞄准镜光学效果共用最终取样，文字控件保持清晰。房间沿用原预算；物品独立预览与永久空场景综合测试分开。

## 空间覆盖与预算

`visible-air.mjs` 只为实际游戏的小鸟、无人机和邻居视角选择世界空气单元。已有粒子拥有稳定的世界锚点和身份；视角决定哪些单元需要运行，不携带已有粒子。风向与重力在世界坐标内计算，保留透视、远近和建筑深度遮挡。视野边缘留 18% 余量并渐隐；邻居使用实际圆形镜片范围，黑色遮罩外不分配全屏预算。夏季虫点仍限制在露台低位，不铺满天空。天台、楼排、远处三种额外审核视角沿用局部效果，不要求完整覆盖。

| 效果 | 固定池上限 | 实际提交 |
| --- | ---: | --- |
| 春季柳絮 | 16 | 可见活动粒子 |
| 夏季虫点 | 20 | 露台低位可见粒子 |
| 秋季花屑和叶片 | 64 | 可见活动粒子 |
| 冬季雪 | 112 | 可见活动粒子 |
| 雨丝 | 840 | 按源画面像素数、镜片面积和雨强限额后，提交可见活动雨丝 |

四季渐变时保留各自固定池。每次出生搜索最多 512 个空气单元、8192 次候选采样；空范围有重试间隔，满池不重复出生搜索。位置缓冲只上传活动部分，颜色等固定属性按身份更新。减少的是运行时更新和绘制压力，未声称减少网络资源加载。雨丝使用真实深度测试和距离雾；天空随眼点居中，方向仍保留世界方位。

天气统一为晴朗、阴天、小雨、大雨、有风、雷雨、台风、薄雾八种。`overcast` 保留原阴天光照，旧 `cloudy` URL、已存选择和调用规范化为阴天。自动节奏、手动过渡、七时段、四季及天气行为保留。
