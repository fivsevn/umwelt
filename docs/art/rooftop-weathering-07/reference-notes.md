## 原照片里实际能看到的区别

- **Photo 1，地坪**：板缝与细裂缝是不同层级。许多接缝只比灰底稍深；中央斜向深痕有宽窄变化，交会处更宽、更深，旁边有少量浅色缺口，外观像曾处理过的窄裂隙。其余细线有些被浅灰擦磨遮弱，并非整条同黑、同宽。台阶根和边缘的灰色积痕随接缝、台阶连续，但局部断开。单凭照片无法确认具体修补材料或含水状态。
- **Photo 2，地坪**：后侧浅暖灰旧面有较安静、连续的中心，细碎剥口主要发生在边缘；花盆底座周围还有偏方的浅磨痕及局部接缝。大部分地坪仍是薄薄的近灰色擦痕、细孔、接缝和少量小缺损。值得保留少数有范围的修补面，不能把所有旧化都拆成均匀孤立小粒。
- **Photo 3，墙面**：窗上横梁、柱脚与屋檐附近的深浅变化有明确位置关系；细灰痕向下延伸，长短、浓淡和终点不同。墙面有细裂线，底灰仍大面积可读。铁杆的褐锈是另一种材料痕迹。本轮不把锈色或瓦面组织移植到水泥，也不改变既有砖红屋顶。

## 可以直接用于原生绘制的构造

### 裂缝：细线与局部补缝带分开

最小源像素继续为 1px，即 16px/m 下的 6.25cm；照片里的毫米级细线无法按真实宽度重现。细薄感应通过邻灰、间断可见与局部深度实现，不缩小网格，也不换平滑取样。

1. 保留一条有方向的主细线，大部分用中灰或较深邻灰。最深色只放在少数交会、转折和短凹段；不要把全部主干和支线等粗描深。
2. 主线的短段长短不同，支线少而不等长，端部逐渐退回邻灰；不要每隔相同距离就转弯或分叉。少数 1px 缺口可以让旧擦磨或补浆遮住线，避免闪电式的完整深轮廓。
3. 需要表现处理过的旧缝时，沿部分线段放 1–2px 窄参差带，最多在交会处稍宽。边屑只贴一部分裂段，左右位置交替，不能每个弯都有同样浅芯或亮边。
4. 板缝继续较直、较弱，与更不规则的细裂缝区分。不要把原有所有接缝一起加深。

### 修补：少数连续旧面，破碎主要发生在边

1. 从现有裂隙／接缝附近选少数修补位置，局部小面可控制在约 8–14px 的范围；形状偏置、伸入缝的一侧稍长，不做相同的方框或圆岛。
2. 中心以底色及 +4/+8 邻色为主，保留较安静的连续区域；边缘用 1–3px 小缺口、旧底侵入和零星矿粉，深浅都不闭合成完整描边。
3. 暖裸露灰只留少量格，不让每个修补都有暖色中心。照片中后侧那类较大的旧修补可以用更低色差保留一个局部面，但不恢复 05 的整块浅黄／深绿对撞。
4. 修补边与擦磨痕应有区别：擦磨可留下少量短方向痕，主要修补的碎片不能又沿同一方向串成长条。

### 旧水痕：从低点／接触边出发，浓淡有终点

1. 地坪从墙脚、台阶根、少数接缝交会或现有修补低点选位置。用较弱邻灰形成不对称薄晕，让一侧积痕稍密、另一侧散开；不能在空地等距放同类潮斑。
2. 少量矿物浅边只出现在薄晕的一部分，1–2px 断续且不封闭；中心和外沿各保留底色空隙。弱色差的痕面可以连贯，最深／最亮碎格反而更少。
3. 墙上从墙顶接触处、柱脚／屋檐下选择不同起点，向下形成 1–3px 宽的断续短竖痕；下端变稀、回归底色，宽度和长度不齐。不要将地坪图案旋转后直接用于墙面。
4. 原生图集表现干后的残留、矿粉与旧返潮色差。蓝色反光、正在积水的镜面或雨点留给既有动态天气层，不烘进所有天气共用的贴图。

## 两个外部补充参考

**[Poly Haven：Concrete Floor Worn 001](https://polyhaven.com/a/concrete_floor_worn_001)**，摄影 Dimitrios Savva、处理 Rico Cilliers。已查看官方 diffuse 预览：主体是连续安静灰面，细划痕、浅缺口和少数深磨痕穿过其间，细节并不均匀占满每处。它补充的是“底面—薄痕—局部缺损”的面积关系；具体修补和水痕仍以用户照片为准，不将高分辨率地图直接缩成像素贴图。

**[Makkon：Textures Concrete](https://makkon.itch.io/makkon-textures-concrete)**。已查看作者公开场景图：矿粉、窄竖痕、建筑接触边和较安静大面并存，体积明暗仍由场景光照承担。可借鉴依附建筑位置的组织方式。作者说明适配 32px/m，本项目保持 16px/m；页面也说明截图可能混用其他材质包，因此不把截图里每种表面都归为该混凝土包。

两处参考都只用于观察；不复制图片、购买替换包、描摹原图或生成新位图。

## 实际场景验收要看什么

先比较同视角阴天近景：能分辨弱板缝、少数不等粗细的裂线、有安静中心的局部修补、靠接触边形成的旧水痕；空地应仍有连续安静底。再看晴天迎光及阴影面是否保留这些关系。若迎光处色阶变淡，先判断光照，不通过全场增加对比或补噪点补偿。重点是三种痕迹各有构造与位置依据，而不是颜色数、覆盖率或随机程度。
