# 东东与小猪方块模型

人物与小猪使用封闭方块，保留不同服装的裁剪、偏分头发、脸部与四足、方耳及折角卷尾。35 套服装和 35 款装饰沿用原目录，动作和天气行为仍由同一套关节控制。

`block-actors.blend` 是真实 Blender 原稿，保存完整的 70 个变体及关节层级；通过 `capture-source.mjs` 记录运行中的实际方块尺寸和关节位置，`build-source.py` 原生建模后独立重开检查。复用原生 Pixelorama `docs/art/rooftop-game/material-book.pxo` 和其 PNG，将实际材料表面标定为 16 纹理像素／米。原模型和游戏低采样由同一个显示规则切换。

独立[东东与小猪测试页](preview/index.html)继续保留。人物也在[统一测试的初始组合](http://localhost:8765/tests/browser/rooftop.html?mode=game)与正式页面核对。测试使用独立初始数据，不覆盖游戏换装记录。动作由游戏与测试共用的 `actor-pose.mjs` 执行。茶杯、剪刀等随动作挂在手部；浇水壶仍使用已完成的原生物品。

修改运行造型时同步模型记录与原稿，独立重开检查封闭方块、关节和完整物理 UV，再核对正式游戏及统一测试。保留全部服装、装饰、动作、天气行为与换装存档。
