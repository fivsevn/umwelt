# 花农时代综合场景测试

`/rooftop/?stage=background` 是唯一的场景测试页。同一页检查北天台、南阳台的材料、天气、季节、时间和六种取景，页面标题为“空场景 · 综合测试”。

从仓库根目录提供静态文件后，打开 [本地测试页](http://127.0.0.1:4173/rooftop/?stage=background)。2026-10-11 建立统一入口；2026-10-12 合并天气选项并调整实际游戏视角的空间空气覆盖。当前原稿与最终采样规格见[美术管线](rooftop-pixel-style.md)，发布与核验见[本轮记录](art/rooftop-air-coverage-01/README.md)。

## 场景与视角

“测试场景”切换北天台、南阳台。“测试视角”提供以下六个选项，均使用游戏共用渲染器和实际建筑：

| 选项 | URL 中的 `view` | 检查用途 |
| --- | --- | --- |
| 天台 | `terrace` | 近处地面、墙面与屋顶，可拖动观察 |
| 楼排 | `row` | 本楼及相邻楼排的整体关系 |
| 远处 | `outlook` | 天空、远景和天气氛围 |
| 小鸟 | `bird` | 游戏小鸟视角 |
| 无人机 | `drone` | 游戏无人机视角 |
| 邻居 | `neighbor` | 游戏邻居视角 |

“自定义天气”“自定义时间点”“自定义季节”提供 8 种天气、7 个时段和四季。多云合并为阴天 `overcast`，旧 `cloudy` 链接及保存值继续兼容。切换场景、视角和环境选项时，当前选择同步写入同一个页面的 URL；刷新或复制链接可以重新打开这一组合。光照和天气继续由现有环境机制更新。

真实空间空气与降水只按小鸟、无人机、邻居三种游戏视角验收，包括移动和变倍后的可见范围；邻居使用有效圆形镜片范围。天台、楼排、远处是额外材料审核镜头，不为这些视角铺满特效。建筑、光影与特效共用最终屏幕像素格，模型不因低采样而削减结构。

例如：[南阳台、小鸟视角、秋天傍晚小雨](http://127.0.0.1:4173/rooftop/?stage=background&scene=south&view=bird&weather=rain&time=dusk&season=autumn)。

## 永久空场景与物品页面

测试页的北天台、南阳台始终没有陈列物品，东东和小猪的模型隐藏。观察入口在验证前丢弃南北陈列，只读保留房间与版本元数据供兼容校验，不将空布局写回存档。公开游戏使用本机存档，综合测试使用隔离的审核会话存储；两者都不能把已有物品带入场景。即使旧链接带有 `layout=local`，进入测试页时也会移除该参数，保持空场景。

“物品页面”打开独立的 [`/rooftop/arrange/`](../rooftop/arrange/) 车库。已有物品、存档读取、编辑和恢复仍由车库处理，继续使用原有存储键与兼容规则。车库无存档或恢复默认时，南北阳台为空，房间保留原有 19 件陈列。房间页面也保持独立。不要从测试观察页恢复陈列或保存空布局到车库存档。

## 旧入口

- `/rooftop/3d/` 自动跳转到统一测试页，默认使用小鸟视角。
- `/rooftop/previews/pixel-01/` 自动跳转到统一测试页，默认使用天台视角。
- `stage=game-model` 和 `test=1` 兼容为 `stage=background`，前者默认使用小鸟视角。

旧链接中的南北场景、天气、时段、季节及有效视角继续带入统一页。两处旧独立 HTML 不再载入自己的场景；关闭 JavaScript 时只提供一个统一入口链接。历史样板的 GLB、PNG、vendor、制作脚本和原稿保留，供原生制作与历史检查使用。
