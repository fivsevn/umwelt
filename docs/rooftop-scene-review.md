# 花农时代综合场景测试

`/rooftop/?stage=background` 是唯一的场景测试页。同一页检查北天台、南阳台的材料、天气、季节、时间和六种取景，页面标题为“空场景 · 综合测试”。

从仓库根目录提供静态文件后，打开 [本地测试页](http://127.0.0.1:4173/rooftop/?stage=background)。这次仅修改测试入口与切换界面；Blender 模型、Pixelorama 原稿、贴图和统一像素尺度保持原样。

## 场景与视角

“测试场景”切换北天台、南阳台。“测试视角”提供以下六个选项，均使用游戏共用渲染器和实际建筑：

| 选项 | URL 中的 `view` | 检查用途 |
| --- | --- | --- |
| 天台 | `terrace` | 近处地面、墙面与屋顶，可拖动观察 |
| 楼排 | `row` | 本楼及相邻楼排的整体关系 |
| 远处 | `outlook` | 天空、远景和天气氛围 |
| 小鸟 | `bird` | 游戏小鸟视角 |
| 无人机 | `drone` | 游戏无人机视角 |
| 邻居 | `neighbor` | 游戏邻居视角 |

“自定义天气”“自定义时间点”“自定义季节”沿用现有 9 种天气、7 个时段和四季。切换场景、视角和环境选项时，当前选择同步写入同一个页面的 URL；刷新或复制链接可以重新打开这一组合。光照和天气继续由现有环境机制更新。

例如：[南阳台、小鸟视角、秋天傍晚小雨](http://127.0.0.1:4173/rooftop/?stage=background&scene=south&view=bird&weather=rain&time=dusk&season=autumn)。

## 永久空场景与物品页面

测试页的北天台、南阳台始终没有陈列物品，东东和小猪的模型隐藏。观察入口不读取本机布局或审核会话陈列，也不将空布局写回存档。即使旧链接带有 `layout=local`，进入测试页时也会移除该参数，保持空场景。

“物品页面”打开独立的 [`/rooftop/arrange/`](../rooftop/arrange/) 车库。已有物品、初始陈列、存档读取、编辑和恢复仍由车库处理，继续使用原有存储键与兼容规则。房间页面也保持独立。不要从测试观察页恢复陈列或保存空布局到车库存档。

## 旧入口

- `/rooftop/3d/` 自动跳转到统一测试页，默认使用小鸟视角。
- `/rooftop/previews/pixel-01/` 自动跳转到统一测试页，默认使用天台视角。
- `stage=game-model` 和 `test=1` 兼容为 `stage=background`，前者默认使用小鸟视角。

旧链接中的南北场景、天气、时段、季节及有效视角继续带入统一页。两处旧独立 HTML 不再载入自己的场景；关闭 JavaScript 时只提供一个统一入口链接。历史样板的 GLB、PNG、vendor、制作脚本和原稿保留，供原生制作与历史检查使用。
