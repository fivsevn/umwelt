# 花农时代综合场景测试

`/rooftop/?stage=background` 是唯一且永久为空的场景测试页。同一页检查北天台、南阳台、空房间的材料、天气、季节、时间和六种取景，标题为“空场景 · 综合测试”。

从仓库根目录提供静态文件后，打开[本地测试页](http://127.0.0.1:4173/rooftop/?stage=background)。原稿与采样规格见[美术管线](rooftop-pixel-style.md)，空气契约见[空间天气](art/rooftop-air-coverage-01/README.md)。

## 场景与视角

“测试场景”切换北天台、南阳台、空房间。房间保留室内观察镜头。“测试视角”提供六种取景，均使用游戏共用渲染器和实际建筑：

| 选项 | URL 中的 `view` | 检查用途 |
| --- | --- | --- |
| 天台 | `terrace` | 近处地面、墙面与屋顶，可拖动观察 |
| 楼排 | `row` | 本楼及相邻楼排的整体关系 |
| 远处 | `outlook` | 天空、远景和天气氛围 |
| 小鸟 | `bird` | 游戏小鸟视角 |
| 无人机 | `drone` | 游戏无人机视角 |
| 邻居 | `neighbor` | 游戏邻居视角 |

“自定义天气”“自定义时间点”“自定义季节”提供 8 种天气、7 个时段和四季。阴天规范值为 `overcast`，旧 `cloudy` 链接与保存值继续兼容。场景、视角和环境选择同步写入 URL，刷新或复制链接可重新打开同一组合。

真实空间空气与降水按小鸟、无人机、邻居三个游戏视角验收，包括移动和变倍后的可见范围；邻居使用有效圆形镜片。天台、楼排、远处用于额外材料审核，不要求铺满特效。建筑、光影和特效共用最终屏幕像素格，模型保持完整。

“画面效果”默认选择“原模型”，用于直接检查原生低模。切到“游戏像素”后，可检查正式页面的共享低采样。选择“狙击手”后，用滚轮、双指或 `+`／`-` 变倍；拉近会同时提高整幅画面的采样，拉远恢复原像素颗粒。查看建筑纹理、边缘、空气特效与镜片刻线是否一致变清楚，再切回小鸟和无人机确认原颗粒保持。空场景页仍不添加物品和角色；物品与角色的效果在对应审阅页面或实际游戏画面核对。

例如：[南阳台、小鸟视角、秋天傍晚小雨](http://127.0.0.1:4173/rooftop/?stage=background&scene=south&view=bird&weather=rain&time=dusk&season=autumn)。

## 空场景与物品

测试页的北天台、南阳台始终没有陈列物品，东东和小猪的模型隐藏。综合测试仅在内存中清空三个场景，不读取或改写个人陈列；带有 `layout=local` 的旧测试链接也不能引入陈列。公开游戏展示本机布局，无存档时展示当前初始布置。

物品测试使用独立的本地页面 `docs/art/rooftop-furniture-02/preview/`。场景和物品测试保持各自的入口与页面风格，需要看哪部分就直接打开哪页。正式车库 `/rooftop/arrange/` 负责摆放、保存与导出；初始陈列保存在 `rooftop/initial-layout.mjs`，共 118 件物件，北天台 83 件、南阳台 14 件、房间 21 件；已有新目录个人布置继续保留。

## 兼容入口

- `/rooftop/3d/` 转到综合测试，默认使用小鸟视角。
- `/rooftop/previews/pixel-01/` 转到综合测试，默认使用天台视角。
- `stage=game-model` 和 `test=1` 兼容为 `stage=background`，前者默认使用小鸟视角。

有效的南北场景、天气、时段、季节和视角参数继续带入统一页。两处跳转页不载入独立场景，关闭 JavaScript 时提供综合测试入口。

相关 Node 检查包括 `rooftop-review.test.mjs`、`rooftop-background.test.mjs`、`rooftop-story-camera.test.mjs`、`rooftop-visible-air.test.mjs` 和 `rooftop-outdoor-raster.test.mjs`。实际浏览器检查南北切换、六种取景、环境选择及刷新、兼容跳转、窄屏控件和手帐，同时确认物品数为零、存档字节不变。
