# 花农时代：像素绘画的低多边形场景

2026-10-08。所有场景、目录、预设和人物使用共享材质库；界面、手帐和目录缩略图是 2D 呈现，游戏主页、车库及 `/rooftop/3d/` 使用同一套可转动的立体模型。既有装扮界面、布局、存档、天气、时刻、音响和门的作用保持一致。

## 参考研究与转译

用户提供的旋转 GIF 属于 Brendan “Sully” Sullivan 的像素 3D 作品。主要规律是清晰的低多边形体块、少量有意选择的色阶、低分辨率贴图绘画和与构造一致的细节：木条、框架、五金、窗反光、面板和磨损。建筑和道具的轮廓具有体积，细节主要由像素绘画承担。

- [酒柜](https://www.artofsully.com/projects/oRk24)：木材分板、橱框、独立玻璃反光；大面积整色配少量像素簇。
- [门与路灯](https://www.artofsully.com/projects/eWQK3)：分层金属结构、把手、通风条与狭窄反光。
- [神社](https://www.artofsully.com/projects/rNW6E)：屋顶与基座独立结构，柔和土色，材质绘画体现接缝与风化。
- [空调](https://www.artofsully.com/projects/XWDP0)：简洁机体配明确的扇叶、格栅和墙面砖缝。
- [作者介绍与教程作品](https://www.artofsully.com/projects/lbEOk)、[作者资料](https://artofsully.itch.io/)：像素绘画与三维体块结合的工作方式。

本项目不使用或复制作者贴图、网格和截图。采用新绘制的整数像素簇与程序化模型，结合原资产逐件列明的植物图鉴、厂商装配图和馆藏资料。模型未确定的背面、厚度和局部纹饰仍为转译推断。

## 游戏中的统一规则

`painted-materials-v6` 的几何保留正常的低多边形轮廓，像素信息来自物体表面的原创绘画。所有贴图由代码绘制到 CanvasTexture；不导入、生成或复制任何图片文件。参考图只用于观察构造、材质绘画及色阶组织。

`face-paintings.mjs` 定义木材、金属、漆面、搪瓷、布料和抹灰。每种材质包含六个分别绘制的面及有限组稳定变化。几何对称时，木结、磕碰、污渍、褪色和氧化的位置也分别定义，不镜像或重复同一面。重复的层板、板条和抽屉按同尺寸部件的稳定序号选择不同绘画。板条和柜门保留实际接缝；纹理不把所有物件画成相同的装饰面板。

表面网格按每单位 12 个像素采样。着色器在各面的实际切平面上取等距格点，再映射回原始绘画；长宽不同的面、斜面及盆壁不会为了铺满而拉成长方形像素。放大几何保留方形表面颗粒，透视和面朝向自然改变屏幕上的形状。纹理使用 nearest 采样；轮廓由正常分辨率与 MSAA 处理，不把整个画面低分辨率放大。

每种材质使用九个相邻明暗色阶，陶瓷纹饰另保留少量本身需要的色料。抖色由单个点组织。稳定的整数散列打散阈值，不使用重复的棋盘或斜线模板。颜色场先描述木结周围的生长纹、局部水痕、钢材反光、边角磨损、布面折痕和抹灰老化，再以离散点表达深浅；并非给所有表面均匀撒噪点。木材保留天然棕色，钢材保留中性灰，陶土保留烧制色，白搪瓷和蓝色水池分别保留自己的釉色。参考物件的颜色不作为本项目的通用配色。

`weathering.mjs` 在室外家具上叠加独立物质：铁件接缝与露边的氧化锈色、木材和漆面潮湿区域的霉与苔藓、下沿的积土。污染围绕少数明确的来源区域集中，有较密的主体和零星的外围，局部阈值阻止远处散点；其余表面保留原材质绘画。塑料不产生铁锈。少量攀附植物从低处关节生长，避开放置平面；室内家具不套用室外污染层。物件、层板和部件的污染位置随稳定 seed 与部件序号错开。

圆台面、曲面与六面体分别映射。连续盆壁不使用六面体展开图；圆桌不使用矩形托盘轮廓。陶盆烧色和釉流是错开位置的点绘色场，内壁及盆底使用独立绘画，包含水渍、积土痕和局部釉色磨损。陶瓷固有纹饰保留器物身份，普通盆壁不重复装饰条纹。泥土、细石及陶盆外观随 seed 稳定变化；移动、旋转和刷新不会重抽。植物使用有叶脉与斑驳的叶片、厚肉质叶和有棱肋的仙人掌，保留与家具不同的质感。

`soil-surface.mjs` 用五圈径向分面和至少 24 个周向分段构成略微隆起的土面，轮廓沿盆口收低；中心偏移、缓坡与局部凹陷随有限组稳定 seed 变化。矩形栽培箱同样有起伏。碎石和土粒沿真实土面高度放置，土粒采用更细的曲面分段；几何缓存和原有承托高度保持共享。

## 共享渲染与性能

场景、目录、预设及人物共用模型与材质。几何、有限组绘画和基础顶点缓存复用；不为每个 seed 建立纹理。批次保留各自 GPU 属性，目录缩略图释放时不影响实时场景。物体移动复用模型，支持关系沿用同一空间定义，不由美术纹理改变放置规则。

画布填充负担由 `render-budget.mjs` 限制。3D 画布使用正常 CSS 缩放，2D 界面保持原有像素显示。实例本色只应用一次，陶瓷图案保留独立色料；最终帧缓冲不取整，以免深色陶土和植物的弱颜色通道被截断。

参考 [Sully 的制作记录](https://www.artofsully.com/blog) 与 [Lospec 的像素 3D 工具说明](https://lospec.com/blender-toolkit/)。每面的绘画是使立体物件呈现材质、明暗与使用痕迹的手段，不把“展开图能单独展示”作为游戏目标。

## 郭里园周边

参考 [濠滨通城里 2022 年郭里园街巷实拍](https://www.sohu.com/a/551257906_121123899)，采用浅米色抹灰的五至六层住宅、坡屋顶、封闭阳台、防盗栏、空调、落水管和狭窄社区道路。[2022 年改造报道](https://js.people.com.cn/n2/2022/1101/c360302-40177396.html) 和 [南通市住建局 2025 年改造报道](https://zj.nantong.gov.cn/ntsfgj/xmdt/content/ead8ba9e-f1c1-408b-ae27-4dbfa8e2689b.html) 支持社区停车、绿化及电动车棚等环境元素。

外围包括八栋住宅、十八处树木绿化、七辆汽车、四辆自行车、七辆电动车、充电车棚、路灯、垃圾桶、长椅和排水口。阳台主体仍沿用用户已有布局，承重建筑向下延伸六层并接到地面。

已检查 Google Maps 的郭里园新村卫星图，楼群以东西向长条住宅和其间窄巷为主；仍未确认 92 幢 604 的精确窗外视角。周边建筑位置、背面和道路组合是参考小区特征的美术构图，不是该住址的测绘，不宣称精确再现 92 幢或其相邻建筑。公开照片只用于观察，不作为游戏图片资源。

## 场景材质与地砖

阳台铺地按每世界单位12个方形像素整片绘制，与物件表面共用像素尺度；每块砖的边长为2个世界单位，砖缝使用接近砖体的浅灰色；每块砖的烧制深浅、孔隙、磨边和缺角独立变化。水泥修补采用尺寸、位置不同的矩形补块，以一个大主块配合较小补块，合计覆盖实际地面约60%，余下约40%保留瓷砖。水泥内部不保留砖缝，施工切边以直线为主，仅在接边留下少量碎砖和裸露胎体。通向门的瓷砖保留更完整的砖面，不随机挖掉边角。北、南阳台的补块安排不同，使用不同的固定种子。潮痕集中在原有排水口，积土和苔藓集中在种植区及墙角，不在完整砖面画孤立折线，也不在整片铺地撒污点。

水泥本体的颗粒由不同尺度的连续灰阶场和方形点抖动组成，少数浅表剥落处保留深色孔隙、裸露细骨料和浅色残皮；墙脚积灰仅集中在各阳台不同的几段边缘。排水口的潮痕带不规则干燥盐边，铺地材质本身的明暗不被污渍替代。

第二次铺设的水泥使用略深的普通灰色色阶，分成不同大小的矩形补块，覆盖实际地面约40%，叠在第一次修补范围内；因此可见地面约为40%较深水泥、20%较浅水泥和40%瓷砖。每一块都使用独立的颗粒、明暗和残皮变化；两种水泥只以灰度与粗糙程度区分，不画成褐色、蓝色或水流蔓延的轮廓。

补块分布在不同位置、大小不同，深浅两种水泥与残留瓷砖交错，不按左、中、右划分连续材质区域。大修补块内另有少量施工接缝，形成错开的T形交汇；每块使用独立灰度偏移和固定种子。接缝用少量较深的方形点表现，不重新铺成规则小方砖。总修补面积和门前完整瓷砖范围保持不变。

本次修补边界依据[Walkway Restoration 施工实拍](https://www.walkwayrestoration.com/past-work)、[旧瓷砖水泥补块实拍](https://www.mobile01.com/topicdetail.php?f=360&t=5187111)和[FHWA 修补切割边界说明](https://www.fhwa.dot.gov/Pavement/concrete/full5.cfm)校准，参考图仅用于观察，未导入游戏。

抹灰墙、灰屋瓦、砖基座和路面使用不同的材质绘制。大面积表面按实际长度取样，并组合独立的绘制区域，避免把64像素拉成长条；对称面、重复部件分别取样。室内墙面不使用室外泥土和苔藓；木地板有错开的接缝、不同的板长与木纹。两侧住户的窗面反光、窗帘、空调、晾晒及封闭阳台分别变化。天台原有范围、物件布局及承载空间保留；外围建筑位置根据地图观察调整。
