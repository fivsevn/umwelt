# 花农时代：原生像素贴面的低模

此页保留 2026-10-10 原生物品图集方案的技术记录，并补充当前建筑资源的归属。当前入口与源稿见 [花农时代维护索引](rooftop-README.md)，场景检查见 [综合场景测试](rooftop-scene-review.md)。新一轮视觉重制的顺序与保留边界见 [仓库梳理](rooftop-rebuild.md)。

2026-10-10。当时的运行版本已通过 PR #60 接入第 8 版样板延伸出的原生图集方案，随后继续修订。默认陈列、存档身份、车库、房间、人物动作、养护与叙事沿用原系统。下文的材质书、目录模型和当轮验证记录属于这套物品方案；建筑后来单独接入已保存 Blender 网格。

## 后续制作原则

实际制作继续使用此前完整的 Blender 模型与 Pixelorama 原稿。像素低模仍须保留器形、比例、厚度、背面、底面、开孔和真实承放结构；纹理画在这些真实表面上。家具不为了让成品更粗糙而额外删减几何，造型调整须来自明确的物件设计任务。本轮不修改家具模型、贴图或放置规格。

原稿质量、材料格和最终屏幕颗粒是三个独立检查对象。Pixelorama 最小格按物理长度统一，粗粝成品由共享的低分辨率场景采样产生。当前认可目标为 2.5 CSS 像素，按真实设备像素比取整数方格；不得通过扩大原稿笔触、缩小贴图、删掉家具结构或给单个对象另加像素化来代替最终采样。

每轮保留可编辑的 PXO／Blend，核对保存与独立重开、导出资源和实际游戏。已有手改原稿不直接回放旧制作脚本。材料修改只改指定范围；模型、UV、镜头、光影、放置和存档分别按任务边界保留。网页不会因保存 Blend 而自动更新，导出接入后还须检查最终发布包。发布与线上核验结果见[本轮空气覆盖记录](art/rooftop-air-coverage-01/README.md)。

## 当前建筑与物品管线

建筑由 `3d/architectural-shell.mjs` 加载 Blender 导出的 `assets/background/empty-rooftop.bin` 与清单。当前原稿为 [rooftop-lowpoly-02](art/rooftop-lowpoly-02/README.md)，[第 07 轮材料原稿](art/rooftop-weathering-07/README.md)和[粗粝低模第一轮](art/rooftop-lowpoly-01/README.md)保留供回溯。各轮都保存 `game-environment.blend` 与真实 Pixelorama `terrace-book.pxo`；运行 `terrace-book.png` 为 1024×1024，清单标定 16 像素/米，单格为 0.0625 米，最近邻取样、不生成 mipmap。另保存远景 `distance-facades.pxo` 原稿。全部主图材质及远景颜色图均在 Pixelorama 审阅整理。裂缝、补浆、水渍和分层磨损属于贴图绘画。第二轮进一步收拢主色阶、以单像素 Pencil 修饰旧化边沿；关闭抗锯齿、使用 BasicShadowMap 和四档间接面光。模型、UV、镜头位置与逻辑取景沿用原版。

户外最终画面另使用 `3d/outdoor-raster.mjs` 的统一方格。用户认可约 3 CSS 像素的粗粝版后，要求两边颗粒只稍微细化：`3d/pixel-grid.mjs` 固定目标 2.5 CSS 像素，取 `round(2.5 × devicePixelRatio)` 个完整设备像素。DPR 2 为每格 5 个实际像素，场景和独立家具近看相同；DPR 1 为 3，DPR 3 为 8，保持方块完整。建筑、太阳阴影、季节粒子和雨丝共用低分辨率离屏绘制，最后按整数方格显示；右边和下边不足一格的部分裁边，不拉伸。原生 16 像素／米的材料格仍保留，画面格与材料格分别检查。邻居镜头的光学变形在最后方格取样时执行，光学遮罩与刻线沿用同一屏幕格；文字控件保持清楚。公开户外、空场景测试及车库户外使用该呈现，房间维持原绘制预算。家具卡片缩略图保持原 128 像素高绘制方式。

目录物品与室内沿用 `native-style.mjs` 的每世界单位 8 像素及 512×512 `material-book.png`。这部分的源稿与制作记录在 [全游戏物品原稿](art/rooftop-game/README.md)，家具重制留到下一阶段。两条管线各有原生标定，下文的 8 像素和 32×32 材质区域指物品方案。

## 天气与实际观察范围

当前天气将多云合并为阴天，规范值为 `overcast`；旧 `cloudy` URL 和已保存选择通过 `weather-condition.mjs` 兼容归一，继续使用原存储键。界面和自动天气池提供 8 种天气，时段与四季机制保留。

柳絮、秋季飘落物、雪和雨使用世界坐标的可见空气体积，保持稳定身份、真实远近和随时间变化的轨迹。检查范围是小鸟、无人机、邻居三个实际游戏观察位置；转头、升降、靠近和改变倍率后仍按实际视锥取样。邻居覆盖按可见镜片而非黑色遮罩计算，夏季蚊虫保持露台低位，不为填满天空而提高数量。雾继续按世界距离建立层次。

不增加随屏幕移动的全覆盖粒子层；天台、楼排、远处三个额外审核视角保留小范围空气和既有预算，不为测试画面铺满效果。世界中的建筑、光影、粒子和雨丝最后共用同一次屏幕方格采样，文字控件保留清晰呈现。

## 物品贴面的统一方格

`3d/native-style.mjs` 固定为每世界单位 8 个像素：单格边长 0.125。轮廓由低模的连续折面、斜面、薄壳组成。模型长宽、实例缩放和斜面倾角都参与实际长度计算，每个面在自身切平面上取正交方格，一格直接对应原生贴图的一个像素；不把整个面拉伸到 32px。原 UV 保留供编辑参考。最近邻采样，不生成 mipmap。

模型保持游戏原有的摆放、旋转与缩放约定；已存档布局没有改为体素坐标。方格是贴面绘画的单位。`renderScale: 1` 仍是这套旧物品材质的配置；当前户外最终呈现另外采用上文的设备整数方格，不能从材质配置推断最终画面粒度。房间、目录画像沿用各自绘制方式。

`3d/native-materials.mjs` 只加载一张实际 Pixelorama 导出的 PNG。平面法线来自实际三角形，避免圆柱的平滑插值改变网格。四档面明暗、室内、昼夜及雨后色调通过共享参数更新；灯与窗的发光参数保留原天气契约；风、鱼、人物与天气动作保留。目录画像等待图集加载，并固定为干燥日间色调。

## 原生材质书

原稿为 `docs/art/rooftop-game/material-book.pxo`，发布图为 `rooftop/assets/pixel/material-book.png`。512×512 图集容纳 214 个独立的 32×32 区域。512 是打包尺寸，每种材质仍为原生 32 像素绘画。全部筆触由真实 Pixelorama 1.2.3 的一像素 Pencil 在整数坐标执行，保存同一 PXO；PNG 与原生 cel RGBA 逐字节核对。

- 抹灰、石板、铁件沿用已认可样板的连贯色块；木材以板缝、顺纹和少量磨损表现，瓦面绘主要瓦缝。
- 室外木材、铁件、布面和漆面另有少量连贯的积土、氧化及湿生痕迹；室内不套用室外污染。
- 37 种器物分别保存外壁和内底绘画。馆藏的铁绘、青花、彩绘和固有器形继续按资料归属。
- 植物区分普通叶、硬叶、斑叶、条纹叶、肉质叶、苔藓、生石花窗面和龟背竹透明开孔；条纹画在叶面，删去浮在叶外的细条盒。
- 86 件馆藏武器保留原资料侧影，在原生方格重画为薄的双面展示片。此部分属于平面侧影转译，尚未逐件制作完整三维背面。

没有使用图像生成。`prepare-book.mjs` 保存整数笔触计划，`author-book.py` 调用 Pixelorama 保存原稿；这些是制作记录。已有原稿的回放默认停止，保护之后的手工编辑。

## 模型与构造

普通盆壁、圆柱和球状体减少到主要折面。盆土保留两圈不规则闭合土面，土粒由贴图表达。屋顶删去细瓦缝凸起，房间地板用连续原生木面表达板缝。

`stand-models.mjs` 提取原花架构造，`rack-grid.mjs` 同时供实际铁条和承放规则读取。黑色金属层架使用宽 0.375、间距 0.5 的层板条，形成可见 0.125 槽缝；宽盆底跨孔，小底物须落在铁条上。稳定层位 ID、原板顶高度和作者初始布局保持。

`cactus-models.mjs` 和 `water-models.mjs` 提取原仙人掌和水盆。龟背竹按 NC State 的攀援茎、交替叶节、裂叶及内部孔洞校准；生石花按 RHS 的成对厚叶、近无茎、平窗面与中央裂隙校准。

304 项目录可在 `docs/art/rooftop-game/game-assets.blend` 编辑，图集已打包。Blender 库由共享构造导入，运行的网格拓扑仍来自共享构造模块。手改 Blend 后需另做导出与接入，保存 Blend 不会自动修改网页网格。原稿库采用种子 1835、默认容器，供资产审阅，不代替玩家存档。
