# 花农时代：像素绘画的低多边形场景

2026-10-08。所有场景、目录、预设和人物使用共享材质库；界面、手帐和目录缩略图是 2D 呈现，游戏主页、车库及 `/rooftop/3d/` 使用同一套可转动的立体模型。既有装扮界面、布局、存档、天气、时刻、音响和门的作用保持一致。

## 参考研究与转译

用户提供的旋转 GIF 属于 Brendan “Sully” Sullivan 的像素 3D 作品。主要规律是清晰的低多边形体块、少量有意选择的色阶、低分辨率贴图绘画和与构造一致的细节：木条、框架、五金、窗反光、面板和磨损。建筑和道具的轮廓具有体积，细节主要由像素绘画承担。

- [酒柜](https://www.artofsully.com/projects/oRk24)：木材分板、橱框、独立玻璃反光；大面积整色配少量像素簇。
- [门与路灯](https://www.artofsully.com/projects/eWQK3)：分层金属结构、把手、通风条与狭窄反光。
- [神社](https://www.artofsully.com/projects/rNW6E)：屋顶与基座独立结构，柔和土色，材质绘画体现接缝与风化。
- [空调](https://www.artofsully.com/projects/XWDP0)：简洁机体配明确的扇叶、格栅和墙面砖缝。
- [作者介绍与教程作品](https://www.artofsully.com/projects/lbEOk)、[作者资料](https://artofsully.itch.io/)：像素绘画与三维体块结合的工作方式。

本项目不使用或复制作者贴图、网格和截图。采用新绘制的整数像素簇与程序化模型，结合原资产逐件列明的植物图鉴、厂商装配图和馆藏资料。模型未确定的背面、厚度和局部纹饰仍为转译推断。

## 游戏中的统一规则

64×64 原创材质由 `paint-recipes.mjs` 与 `pixel-materials.mjs` 定义。木材以板缝、明暗边和木结为主；金属用稀疏漆面破损；墙面为浅色旧抹灰；屋瓦按错列瓦片绘画；玻璃用阶梯反光。植物保留本身的颜色，普通叶片、厚肉质叶和带棱肋的仙人掌分别构造。花盆和水盆有封闭的盆壁与内壁，花盆保留排水孔，灰色水槽与蓝色水池台分别保留排水板和宽沿。

普通表面贴图随物体旋转，每单位 16 纹素；门、玻璃、空调等面板各有完整像素画。场景按设备上的 CSS 像素输出，不使用平滑过滤，也不在画面上叠随机噪声。物体表面的像素细节与轮廓相互配合，避免用一层屏幕马赛克替代材质。

几何通过实例复用控制负担。叶片使用可复用的封闭面片，仙人掌按轮廓及棱数复用，盆器按器形缓存；同色收藏截面按连续像素合并。目录缩略图从同一模型投影生成，因此换盆、换株形和场景中实际放置的模型一致。

## 本轮材质与光影

依据新的酒吧、办公桌、工作台和植物参考，家具采用暖棕木材、蓝灰金属、深色接缝和清楚的受光边。每块木板保留沿板长方向的纹理、木结和不同的局部色差；细铁网不再被全宽亮边覆盖。墙面修补、铺砖、房间木地板与周边建筑共用这一层色彩关系。背景树木改为分层薄片叶簇，不用几个椭球代表树冠。

参考 [Sully 的制作记录](https://artofsully.com/blog) 中的几何、纹素与 UV 对齐方法，以及 [Lospec 的像素 3D 工具说明](https://lospec.com/blender-toolkit/) 中的最近邻采样、有限色阶与材质明暗方法。所有绘画仍由代码生成，未导入参考图像或模型。普通叶片更薄，轮廓有阶梯；肉质叶保留厚度，龟背竹的裂叶用实际边缘凹口构造。草本和灌木在茎的多层节位长叶，蕨类和藤本形成有空隙的枝叶簇。

陶盆绘画加入轮痕、烧色云斑和局部釉色变化。土面同时使用结块、细裂纹绘画和少量真实的土粒、细石。`surface-variation.mjs` 将物件 seed 转为稳定的纹理相位、色温及颗粒分布；移动、旋转和刷新不会重抽外观，换株形时才随 seed 变化。变化复用同一材质和基础顶点，仅在实例中保存少量种子与接触属性，避免为每个 seed 新建整张贴图。

着色先应用实例本色，再选择绘画色阶。目录的离屏画布与游戏场景保留相同的颜色转换，不对最终帧缓冲直接取整，避免弱绿色与蓝色被截断后出现红陶阴影变血红、叶片变黑的问题。陶瓷纹饰保留独立色料；五级材质绘画与实际光照共同形成层次。

## 郭里园周边

参考 [濠滨通城里 2022 年郭里园街巷实拍](https://www.sohu.com/a/551257906_121123899)，采用浅米色抹灰的五至六层住宅、坡屋顶、封闭阳台、防盗栏、空调、落水管和狭窄社区道路。[2022 年改造报道](https://js.people.com.cn/n2/2022/1101/c360302-40177396.html) 和 [南通市住建局 2025 年改造报道](https://zj.nantong.gov.cn/ntsfgj/xmdt/content/ead8ba9e-f1c1-408b-ae27-4dbfa8e2689b.html) 支持社区停车、绿化及电动车棚等环境元素。

外围包括八栋住宅、十八处树木绿化、七辆汽车、四辆自行车、七辆电动车、充电车棚、路灯、垃圾桶、长椅和排水口。阳台主体仍沿用用户已有布局，承重建筑向下延伸六层并接到地面。
