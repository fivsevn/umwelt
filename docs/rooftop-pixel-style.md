# 花农时代像素制作管线

游戏采用完整 Blender 模型、Pixelorama 原生贴图和统一的最终低采样。入口与资源归属见[文档入口](rooftop-README.md)，实际页面检查见[综合场景测试](rooftop-scene-review.md)。

## 制作原则

像素画风的模型仍须完成器形、比例、厚度、背面、底面、开孔和真实承放结构。纹理绘制在真实表面上，家具不为了让画面粗糙而额外删减几何。造型和几何只按明确的物件设计任务调整。

原稿细节、物理材料格与最终屏幕颗粒分别检查。Pixelorama 的最小像素格按实际长度统一，粗颗粒成品由共享低分辨率采样产生。不通过扩大笔触、缩小贴图或给单个对象追加像素化来代替最终采样。

修改前确认 PXO／Blend 与运行资源的对应关系。原稿保存并独立重开后，核对导出、游戏内接入和最终发布包；保护已有手改，不能直接回放制作脚本覆盖原稿。保存 Blend 不会自动更新网页模型。修改材料时保持模型、UV、镜头和存档契约，除非任务明确要求调整。

## 最终画面

户外通过 `3d/outdoor-raster.mjs` 共用低分辨率离屏渲染，再按 `3d/pixel-grid.mjs` 的整数方格显示。目标为 2.5 CSS 像素，每格实际边长为 `round(2.5 × devicePixelRatio)`：DPR 1 为 3 像素，DPR 2 为 5，DPR 3 为 8。场景与独立家具近看共用此规格，方块保持完整；右边和下边不足一格的部分裁边，不拉伸。

建筑、光照、阴影、季节粒子和雨丝共用这次采样。邻居镜头的光学变形在最终方格取样时执行，遮罩与刻线沿用同一格，文字控件保持清楚。公开南北、空场景测试及车库户外采用这条管线；房间和目录缩略图维持各自绘制预算。

## 建筑材料

`3d/architectural-shell.mjs` 加载 Blender 导出的 `assets/background/empty-rooftop.bin` 和清单。当前[建筑源文件](art/rooftop-lowpoly-02/README.md)包含 `game-environment.blend`、真实 Pixelorama `terrace-book.pxo` 及远景 `distance-facades.pxo`。主图 `terrace-book.png` 为 1024×1024，标定 16 像素／米，单格边长为 0.0625 米；最近邻取样，不生成 mipmap。

地面、墙面、屋顶和远景按同一物理格检查，正面、侧面、背面、底面均核对 Blender 材料绑定。远景由 `baked-pixel-grid.mjs` 在原烘焙 UV 上取正交面格，窗灯数据图共享坐标。当前建筑采用平面着色、四档间接面光和 BasicShadowMap；太阳、发光窗与雾保留环境变化。

裂缝沿实际受力与接缝分支，修补保留新旧浆面的细微层次，水渍结合积水、墙根和排水位置绘制。使用细碎、连贯且不规则的材料痕迹，避免条带、平铺斑块和等间隔重复。

## 家具与现有物品

新家具沿用完整 Blender＋Pixelorama 工作流，物理材料格与建筑对照；当前独立家具模型为正方 16 像素／米。先检查源模型及贴图，再放进游戏三视角核对轮廓、承放、遮挡和最终颗粒，物品预览使用独立页面，空场景页永久保持无物品。

现有物品、人物与室内使用[物品源文件](art/rooftop-game/README.md)和 `assets/pixel/material-book.png`，由 `native-style.mjs`、`native-materials.mjs`、`native-book.mjs` 接入，标定为每游戏世界单位 8 像素。世界单位与建筑米制坐标不同，不能将数值直接全局替换。

每个面在自身切平面上取正交方格，一格对应贴图的一个像素；模型长度、实例缩放和面倾角参与实际换算，不把整面拉伸到固定宽度。`surface-grid.mjs` 的 CPU 入口与运行着色器保持一致。现有布局继续沿用摆放、旋转、缩放、seed 和 ID 约定。

原生材质书 `material-book.pxo` 导出为 512×512 PNG，包含 214 个独立的 32×32 材料区域。Pixelorama 使用一像素 Pencil 和整数坐标，导出 PNG 与原生 cel RGBA 核对。木纹、氧化、湿生、布面磨损及器物内外壁按各自材质绘制，室内材料不统一套用室外污染。[器物与材质资料](rooftop-art-sources.md)提供来源依据。

`game-assets.blend` 是可编辑目录库，网页物品目前由共享构造模块建立；Blend 手改后须另行导出并接入。`stand-models.mjs` 和 `rack-grid.mjs` 共用花架构造与承放规则，修改孔隙或厚度时同步核对承放。盆土保持闭合面，叶片开孔属于实际表面结构。馆藏武器中的双面侧影仍须与完整三维家具分别验收。

`docs/art/rooftop-legacy-materials/` 的材质准备工具仍供原稿与检查调用；`face-paintings.mjs` 提供正式模型的共用函数。2D 回退和图鉴绘制继续保持兼容。

## 空气与天气

柳絮、落叶、雪和雨使用真实世界坐标，保留稳定身份、远近层次、遮挡和连续轨迹。覆盖范围是小鸟、无人机、邻居三个游戏视角，包括移动、转头和变倍后的可见区域；邻居按有效圆形镜片分配预算。夏季蚊虫保持露台低位，雾按世界距离变化。天台、楼排、远处用于额外材料审核，不要求铺满特效。

8 种天气以 `overcast` 作为阴天规范值，`cloudy` 仅为兼容输入。光照、太阳方向、季节和天气资料见[环境制作说明](art/rooftop-atmosphere-01/README.md)。发布及运行核验见[场景核验](art/rooftop-air-coverage-01/README.md)。
