# 天台目录扩充与绘制依据

这轮保留天台背景、页面布局和原有存档身份，新增20种仙人掌、20种多肉、12种苔藓；110种植物、29种花盆、21种家具。新增器具7件、小物8件、小鱼容器3件、灯具4件。全部由整数画布代码绘制，不读取图片资产。

## 资料使用

标准植物图鉴提供学名、形态和养护线索；日本 PUKUBOOK 用于园艺名交叉对照，不作为命名分类的唯一依据。另参照 [伊豆シャボテン動物公園的温室介绍](https://izushaboten.com/saboten/)、[日本植木协会《緑化通信》511号](https://www.ueki.or.jp/media/niwa_navi/2025/09/20250901_1602_11_1908.PDF) 对球体、棱肋与软硬叶系的观察。植物花色表示辨识特征，不表示所有季节同时开花。园艺名有地区差异，手帐同时保留学名。金晃丸采用 Kew 的 Parodia lenninghausii 拼写，旧图鉴写作 leninghausii。

北天台照片 IMG_2205、2206、2207、2210、2212、2213、2214、2216、2217、2220、2221、2222 提供家具杂物结构：铁架网格、斜撑、支脚、白色篮架、木台、泡沫箱、蓝框弯门罩、搪瓷盆、蓝色水池、温湿度表、毛巾、卷管。照片中的物件不被推定为特定年代的古董。没有把照片复制到线上资产。

有明确历史出处的物件在手帐给出馆藏资料：Met 锡灯笼（10.125.599c）、明代青花莲塘纹瓷墩（1993.386.33），以及 Kew 沃德箱史料。绘制提取结构与纹饰，属于像素转译；灯笼在游戏里使用夜间电光。

## 分类与摆放

按仙人掌、多肉、观叶、香草、藤蔓、花卉、蔬果、苔藓、小鱼、家具、器具、小物、花盆、灯具排序。旧水盆归小鱼，苔藓独立；旧空盆归花盆。

植物的承重点按所选花盆的底部或支脚计算，随缩放与旋转转换；枝叶可探出。花架承重范围仍需落在天台内，画面允许每边最多8像素的小幅外伸。盆底也可落在有效花架的架面内。移动、旋转、缩放、换盆、删除、导入使用同一判断，架子不得离开它正在承托的盆底。导入先清洗所有物件，再检查支撑，避免物件顺序影响结果。

灯具亮度随昼夜平滑变化，夜里亮、白天灭。发光绘制在材料夜色之后，使用离散像素光圈，无外部光效素材。小鱼持续游动，苔藓与植物保留透明背景和短接地阴影。
