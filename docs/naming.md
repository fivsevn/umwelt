# 游戏名称与标识

[共用文档](README.md) · [目录与扩容](structure.md)

每个游戏同时有稳定的目录标识、桌面文件名和可读标题。运行时登记在 [`shared/games.mjs`](../shared/games.mjs)，桌面与游戏页面共同读取。

| 仓库目录 / URL | 桌面文件名 | 中文标题 | English title | 日本語タイトル |
| --- | --- | --- | --- | --- |
| `tick/` | `TICK.SYS` | 三个信号 | Three Signals | 三つの信号 |
| `isopoda/` | `ISOPODA.EXE` | 等足目赋格 | Isopoda Fugue | 等脚目のフーガ |
| `rooftop/` | `ROOFTOP.EXE` | 花农时代 | Horticultural Era | 園芸時代 |
| `ophidia/` | `OPHIDIA.EXE` | 体温调节 | Thermoregulation | 体温調節 |
| `gtb/` | `GTB.BIO` | 爬爬电子管 | Gtuber | ジーチューバー |
| `gsm/` | `GSM.BIO` | 爬爬在线 | Gstream | ジー投稿 |

`gtb/` 与 `gsm/` 当前公开图标与入口占位，平台功能仍在制作中。

## 使用规则

- **目录标识**使用小写英文；目录和公开 URL 保持一致，如 `rooftop/`。目录名不加 `.EXE` 或 `.SYS`，也不随翻译改变。
- **桌面文件名**是 UMWELT 桌面图标的程序标识，在所有语言下保留完整英文大写及扩展名。窗口中出现程序标识时也使用相同写法。
- **可读标题**用于图标副标题、游戏标题、浏览器标签页、README 和当前维护文档，按所选语言显示。英文每个单词首字母大写；`Thermoregulation` 是一个单词。
- 桌面语言切换只翻译可读标题，固定文件名保持一致。游戏内的环境名称、实验室、车库和房间属于各游戏的内容，不另建游戏目录标识。
- 浏览器标签页使用 `English title / 本地标题`，英文模式只显示英文标题。子页面可以在前面加本地化的子页面名称。花农时代的标签页跟随桌面语言；这不表示其全部游戏正文已完成多语言翻译。
- 等足目的鼠妇语属于该游戏的附加语言；程序标识仍为 `ISOPODA.EXE`，现有鼠妇语文本独立保留。

## 修改与核对

修改可读标题时，更新共享标题表、对应 HTML 的初始标题、根目录三语 README、游戏 README 与现行文档。新增游戏还需按[目录与扩容](structure.md)登记入口和检查。

标题调整不改变存档键、资源 ID、目录或 URL。历史报告、引用原文和旧版验证记录保留当时的名称；继续开发时以本页及共享标题表为准。

运行 `node tools/check-all.mjs`，并按[测试导航](../tests/README.md)核对三语桌面、文件名、游戏标签页及游戏内语言切换。
