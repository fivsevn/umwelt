# 花农时代共享像素 3D 资产

更新于 2026-10-08。主页面、车库、房间与 3D 试玩页使用同一模型构造。公开天台默认拖动平移、滚轮或双指缩放，Shift 拖动旋转、Home 复位；最小视图限于当前阳台，最大 3.5 倍。南北两侧在同一房屋数据中连接，只渲染当前一侧和相邻屋檐。车库物件拖动与房间服装界面保留原有操作。

模型是依资料制作的像素转译，不是品牌或博物馆器物的精密复制。参考资料支持植物排列、器物构造与材料；配色和在游戏中的宽深占地沿用原布局。资料无法确定的背面、厚度与局部纹饰是明确的建模推断。植物花果沿用辨识图鉴的表现，不代表现实同时开花结果。普通家具资料以厂商装配图、产品页和 RHS 等机构的器具资料为依据。

## 构造与渲染

- 110 种植物：90 种结构规则，三棱茎、两列截叶、裂缝、叶序、棱肋与刺座、复叶和苔藓分枝。个体种子保持确定性，换株形改变生长分布。
- 29 只盆：20 种器形，真实中空口沿、盆壁、底与盆足；按盆型分配叶土面高度，种植袋和方盆单独构造。
- 64 种家具、园艺器具与旧物件：显式构造，未定义资产抛错，避免无资料时生成默认方块。目录与手帐的器物图由同一模型的离屏正交投影生成。植物缩略图也由对应模型生成，手帐仍为固定的 2D 像素图。
- 86 件收藏：以既有馆藏/厂商资料支持的侧轮廓为基础生成实体像素截面，按木材/金属分配厚度；截面厚度为推断，尚未声称是精密三维扫描。
- 35 套人物衣服、35 套小猪配饰：沿用原作者的 2D 设计，7 个结构系列，各 5 色；活动具有对应的手臂、工具与姿态。

采用低多边形实体与原创 64×64 像素绘画贴图：木材的板缝、木结，金属的磨损，陶器的彩绘，植物的叶脉，玻璃的阶梯反光和空调的扇叶均属于材质。贴图最近邻采样、关闭抗锯齿、平面光照、63 级输出色阶；细颗粒固定，不新增风格调节界面。普通表面按物件自身的尺度投射，每世界单位 16 纹素，专用门板和窗玻璃按独立面板布局。叶片、仙人掌及圆形物件使用可复用的封闭面片，避免密集体素壳和逐叶独立绘制。收藏按相同颜色的连续像素截面合并，保留资料支持的轮廓。

实例化合批，场景按需生成、目录缓存离屏缩略图，界面和存档版本保留；无法创建 WebGL 时保留原 2D 游戏。完整美术方法、参考作品和小区来源见 [像素贴图风格说明](rooftop-pixel-style.md)。
