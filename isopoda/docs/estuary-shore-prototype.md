# 河口岸边原型

入口：`/isopoda/?habitat=estuary`，选择「新建观察」。沿用 384 × 430 整数像素世界、既有旧终端界面、汽水等足目名录与收藏系统。新存档以 `estuaryShoreVersion: 1` 区分；旧六段观察及更早的九段存档仍使用原有解码与结束记录。

- 河侧、汽水交界、海侧共用一个潮位。岸上脚印只换观察点，不推进时间；岸上脚印标注目的地；到达两端后只显示可继续走的方向，不循环跳回。
- 先选择沿水线或遮蔽处观察，记录眼前的岸边，再由「继续观察」推进涨潮、满潮、退潮、低潮。八次观察后沿用独立结束页，两轮潮汐是原型的节奏安排。
- 水线在同一块砂泥、石头和漂流木上平缓移动。每轮抽取二至三种，共十二只固定身份个体，依微栖地分配三个观察点：C. carinata 与 J. ischiosetosa 只在河侧，其他种类按湿木、石下、藻边的种类规则和本轮种子形成局部分布，不强求等量，也不保证每个点都有个体。涨退潮和降雨不改变河侧限定种类的站点归属；满潮或低潮的部分观察中，个体留在遮蔽物内而不可见；这是保守的游戏分布规则，不声称它们无法耐受更高盐度。入场与结束页每种显示一只。路线由固定种子生成，包含短程爬行、停顿、换向与泥栖个体的部分遮蔽；动作速度与停顿时长不是生物学测量。旧七只近岸存档保留原有身份、记录并补足十二只。
- 少量银灰鱼影、停歇的底栖小鱼、洞口小蟹与虫迹是环境意象。没有新增物种鉴定，也不把现有 Cyathura carinata 误标为 Cyathura muromiensis。
- 雨后状态由种子决定，约七轮中一轮，在第二轮来水时改变水色与一句观察。左侧显示水深（m）、盐度（‰）、流速（cm/s）与定性的潮汐状态；右上角为三个观察点的无单位、不等距局部坐标。这些尺度均为创作参数，坐标不对应地理定位；换位置才换坐标，继续观察只改变潮位与水文。
- 减少动态效果时，水线直接到达目标，鱼蟹、等足目与芦苇仍保持较缓的可见活动；不能把系统偏好当成暂停。实验室 FLOW 由使用者显式开关。

## 实验室

环境实验室 ESTUARY 默认进入近岸版本，观察菜单附有三个位置 × 四种潮位的十二种布局。背景、石块、沉木、草丛均与游戏共用绘制器，可以分别编辑、导出、重新导入。旧六个观察布局仍在同一个菜单中，用于旧存档兼容和比较。实验室不修改游戏存档。

新增 Lekanesphaera levii 标本及形态实验室参考；Jaera ischiosetosa 加入低盐石下抽取池。Cyathura carinata 的细长轮廓收进源画布并缩小标本展示，参考体长来自 DORIS 的成体范围，不从最大值推算均值。环境实验室附有微栖地依据及抽取、数量、路径的创作边界。Credits 仅补充来源机构主页。

浏览器回归覆盖 320 × 568、390 × 844、1440 × 900；三个位置、完整八次观察、四种语言、刷新续接、笔记、收藏、结束与新建重置；实验室十二种布局的编辑与导入导出，以及游戏存档隔离。

操作提示复用 interactionCue，位于叙事与选项下方、继续观察按钮上方。开场提示以「沿哪边再走走？」起句，说明点击脚印或留在这里；之后缩短为叙事问句。脚印用 Canvas 整数像素绘制，生物、摆动芦苇和水纹均为代码动画，无新增图片请求。

三处基础地形独立：河侧为深色河湾与局部对岸尖角，交界为弯曲砂泥舌，海侧为斜向开阔砂岸。淡水偏灰绿、海水偏蓝绿，两者沿曲折水带掺混，并以像素抖动柔化边界。岸线公式由游戏与环境实验室共用，四个潮位保持原水位差。脚印采用前掌与分离脚跟的整数像素轮廓，按各处岸线切向转动；暗内壁与下缘亮泥形成浅凹痕。

倍速 1× / 16× / 64× 连续推进河口生物、芦苇与水面动画时钟，不推进叙事潮位。等足目复用点按防御、长按捧起、拖动放下；抓取期间暂停自主运动，恢复时从放下的位置继续，手势时长不受倍速影响。

水色与浅深水通过有限色阶连续混合，湿泥边缘也柔化过渡，保留整数像素颗粒。导航脚印固定在画面两侧，不跟随镜头缩放或平移；切换观察点时按当地岸线调整朝向。

## 河口分布、分支与结局

`shore-fauna.mjs` 是画面、物种标签、叙事和记录共享的分布规则。C. carinata / J. ischiosetosa 限河侧；L. hookeri 偏河侧与交界；L. rugicauda 可取三处；L. levii 与 I. chelipes 取交界或海侧的石边、藻边。后三项是根据微栖地进行的游戏站点映射，不是实测盐度区间。每种有本轮固定的主要位置，少数个体可分布在另一个适合的位置。允许整处没有本轮种类，也允许本次全部躲在遮蔽物中。空画面只记录“未见”，不推断局部灭绝、死亡或迁走。

走动选择地点，每轮选择水线或遮蔽处的观察方向，再继续推进八次潮汐观察；没有强制玩家找到虫的门槛。每次按地点的历史记录分为初次看见、再次看见、未见后重现、看见后未见、持续未见。水色、潮位、雨后来水的环境段落和实际可见分支组合；笔记保存当时的地点、潮位、可见种类和分支，刷新后不重抽。

结局由八次实际记录确定：全程未见为“空着的那一栏”；见与未见并存为“错开的岸边”；各次均见沿用“水边还在”。三者没有成功失败等级，不要求连续追踪同一个体。旧结局 ID 与存档仍可读取。

环境实验室的十二处近岸布局共用游戏底图；FLOW 仅预览水流、植物及等足目之外的环境生物动画，不生成游戏虫群。比例参考标本始终由 GAME SCALE 独立控制，不读取或写入游戏存档。

## 回合行动目标与落点重规划

每回合提供“沿水线观察”和“留意遮蔽处”两个观察方向。涨潮、满潮、退潮和低潮分别形成新湿边、背水庇护、退水湿边、低潮湿润遮蔽的行动目标；泥栖、石下、木边、藻间类型保留各自的目标偏好。选择决定呈现的行为片段，不意味着观察本身驱动动物。

目标到达后进入有个体差异的停顿、短程探索和转向。拖动后的起点是实际落点，重新选择附近合适的庇护目标，删除旧路线的平移偏移。个体在同一遮蔽物周围分散使用位置，并维持用于辨识的视觉间隔；这不是野外距离或速度测量。上述行动规则用于游戏；环境实验室 FLOW 仅播放环境动画。

河口开场、分支、记录和结局不使用“你”“我”称谓；叙事用“它们”、身体和轮廓，不出现等足目分类名词。科学术语留在资料记录与实验室。
