# 河口岸边原型

入口：`/isopoda/?habitat=estuary`，选择「新建观察」。沿用 384 × 430 整数像素世界、既有旧终端界面、汽水等足目名录与收藏系统。新存档以 `estuaryShoreVersion: 1` 区分；旧六段观察及更早的九段存档仍使用原有解码与结束记录。

- 河侧、汽水交界、海侧共用一个潮位。岸上脚印只换观察点，不推进时间；岸上脚印标注目的地；到达两端后只显示可继续走的方向，不循环跳回。
- 「继续观察」记录眼前的岸边，再推进涨潮、满潮、退潮、低潮。八次观察后沿用独立结束页，两轮潮汐是原型的节奏安排。
- 水线在同一块砂泥、石头和漂流木上平缓移动。每种潮位都能看见一只沿木边或石脚爬行的等足目，退潮与低潮再露出第二只；七只标本仍进入原有收藏逻辑，其余留在遮蔽中。
- 少量银灰鱼影、停歇的底栖小鱼、洞口小蟹与虫迹是环境意象。没有新增物种鉴定，也不把现有 Cyathura carinata 误标为 Cyathura muromiensis。
- 雨后状态由种子决定，约七轮中一轮，在第二轮来水时改变水色与一句观察。左侧显示水深（m）、盐度（‰）、流速（cm/s）与定性的潮汐状态；右上角为三个观察点的局部坐标（m）。这些尺度均为创作参数，坐标不对应地理定位；换位置才换坐标，继续观察只改变潮位与水文。
- 减少动态效果时，水线直接到达目标，鱼蟹、等足目与芦苇仍保持较缓的可见活动；不能把系统偏好当成暂停。实验室 FLOW 由使用者显式开关。

## 实验室

环境实验室 ESTUARY 默认进入近岸版本，观察菜单附有三个位置 × 四种潮位的十二种布局。背景、石块、沉木、草丛均与游戏共用绘制器，可以分别编辑、导出、重新导入。旧六个观察布局仍在同一个菜单中，用于旧存档兼容和比较。实验室不修改游戏存档。

形态实验室没有新增物种或形态，因此沿用原有目录和来源。环境说明已区分现有水文参考与本原型的创作参数；Credits 无变动。

## 验证

```sh
node isopoda/tools/check-all.mjs
BASE_URL=http://127.0.0.1:8873 node tests/browser/estuary-shore.cjs
BASE_URL=http://127.0.0.1:8873 BROWSER=webkit node tests/browser/estuary-shore.cjs
BASE_URL=http://127.0.0.1:8873 node tests/browser/estuary-shore-motion.cjs
BASE_URL=http://127.0.0.1:8873 BROWSER=webkit node tests/browser/estuary-shore-motion.cjs
```

浏览器回归覆盖 320 × 568、390 × 844、1440 × 900；三个位置、完整八次观察、四种语言、刷新续接、笔记、收藏、结束与新建重置；实验室十二种布局的编辑与导入导出，以及游戏存档隔离。

操作提示复用 interactionCue，位于叙事与选项下方、继续观察按钮上方。开场提示以「沿哪边再走走？」起句，说明点击脚印或留在这里；之后缩短为叙事问句。脚印用 Canvas 整数像素绘制，生物、摆动芦苇和水纹均为代码动画，无新增图片请求。

三处基础地形独立：河侧为深色河湾与局部对岸尖角，交界为弯曲砂泥舌，海侧为斜向开阔砂岸。淡水偏灰绿、海水偏蓝绿，两者沿曲折水带掺混，并以像素抖动柔化边界。岸线公式由游戏与环境实验室共用，四个潮位保持原水位差。脚印采用前掌与分离脚跟的整数像素轮廓，按各处岸线切向转动；暗内壁与下缘亮泥形成浅凹痕。

倍速 1× / 16× / 64× 连续推进河口生物、芦苇与水面动画时钟，不推进叙事潮位。等足目复用点按防御、长按捧起、拖动放下；抓取期间暂停自主运动，恢复时从放下的位置继续，手势时长不受倍速影响。
