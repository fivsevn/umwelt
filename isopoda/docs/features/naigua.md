# 奶瓜虫

奶瓜虫作为鼠妇登记在共享物种目录。与其他鼠妇共用 renderModel、pixelAnatomy、sceneActorPixels、makeIndividuals 和交互状态机；不使用独立访客绘制器或独立点击系统。形态实验室直接提供同样的分解、部位、展开与卷球展示。

形态取自共用卷球鼠妇模板，采用黄色配色和两侧分开的大绿眼黑瞳。cephalon.eyeWhite / eyePupil 控制眼睛配色；conglobation.eyesVisible 允许卷球时保留同一眼睛模块。卷球为无背板纹路的黄色正脸，朝向固定，保留原有对称浅笑与嘴部明暗像素，去掉两侧上翘的外端嘴角，剩余两侧弧线使用较淡的嘴角色；卷球黑瞳恢复参考图的完整形状；触碰后的防御时间为 3.6 秒。资料属于虚构 meme 设定，无真实学名、体长或科学来源，未知字段明确保留“不详”。

新观察通过 drawCohort 抽取，8% 概率出现 1–2 只（陆地按本轮种子随机选择替换槽位、保持七只；保底也随机选位，刷新不重排，其他环境追加），深海排除。加入正常 cohort，拥有唯一标本 ID，并按其他鼠妇一样存档、收集和记录。普通主物种抽取池不包含 rare 物种，避免整组生成奶瓜虫。历史存档不额外生成个体，长度校验允许非深海群体附加至多两只奶瓜虫。

环境实验室没有专属卡片、资料或预览；其原有通用比例参照选择器随共享目录自然增加该种。形态和背景资料只进入形态实验室。

所有新观察共享 naiguaMisses 计数。连续七次未遇到后，下一个非深海新观察保底一只；深海累积未遇次数但不消耗保底。遇到后清零并重新开始七次计数。刷新、继续观察和叙事推进不计次。旧收集存档无此字段时从零开始。

奶瓜虫的 ecologySpecies 随存档保留，取被替换个体或当前群体的一种普通鼠妇。移动参数、环境偏好、河口栖息分布和藻场特定速度使用该参照；形态、名称、收集身份及较长的正脸卷球仍属于奶瓜虫。旧版未开始的陆地入场群体会转换为七个槽位；已经开始的历史观察保留个体身份。

展开形态复用鸭仔的身体比例和解剖模块，保留奶瓜虫黄色、绿眼与面部特征。卷球使用独立保留的宽度参数，各生长阶段的卷球像素与已确认版本一致。

卷球启用 preservePixels：场景绘制至少保留原始 1:1 像素，放大时使用整数倍，跳过常规 0.88 倍及环境比例导致的脸部像素丢失。普通状态仍使用通用场景比例。
