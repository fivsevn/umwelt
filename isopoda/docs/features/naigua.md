# 奶瓜虫

奶瓜虫作为鼠妇登记在共享物种目录。与其他鼠妇共用 renderModel、pixelAnatomy、sceneActorPixels、makeIndividuals 和交互状态机；不使用独立访客绘制器或独立点击系统。形态实验室直接提供同样的分解、部位、展开与卷球展示。

形态取自共用卷球鼠妇模板，采用黄色配色和两侧分开的大绿眼黑瞳。cephalon.eyeWhite / eyePupil 控制眼睛配色；conglobation.eyesVisible 允许卷球时保留同一眼睛模块。卷球为无背板纹路的黄色正脸，朝向固定，保留浅笑；触碰后的防御时间为 3.6 秒。资料属于虚构 meme 设定，无真实学名、体长或科学来源，未知字段明确保留“不详”。

新观察通过 drawCohort 抽取，8% 概率增加 1–2 只，深海排除。加入正常 cohort，拥有唯一标本 ID，并按其他鼠妇一样存档、收集和记录。普通主物种抽取池不包含 rare 物种，避免整组生成奶瓜虫。历史存档不额外生成个体，长度校验允许非深海群体附加至多两只奶瓜虫。

环境实验室没有专属卡片、资料或预览；其原有通用比例参照选择器随共享目录自然增加该种。形态和背景资料只进入形态实验室。

所有新观察共享 naiguaMisses 计数。连续七次未遇到后，下一个非深海新观察保底一只；深海累积未遇次数但不消耗保底。遇到后清零并重新开始七次计数。刷新、继续观察和叙事推进不计次。旧收集存档无此字段时从零开始。
