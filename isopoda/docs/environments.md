# 环境扩展指南

[返回文档导航](README.md) · [扩展工作流](expansion-guide.md)

先区分“同一环境的新布景”“现有模式的新环境”和“新的运行模式”。三者影响范围不同，当前系统不提供任意环境插件的自动注册。

## 1.0 上线环境范围

上线前环境数量冻结为以下顺序；除修正资料、视觉和布局外，不再横向新增自然环境：

1. `terrestrial` — 腐殖层
2. `freshwater` — 淡水腐殖池
3. `groundwater` — 地下水·石灰岩洞穴
4. `estuary` — 河口汽水带
5. `intertidal` — 潮间带岩池
6. `sandy-surf` — 沙滩浪区
7. `shallow-marine` — 近岸浅海·藻场
8. `abyssal` — 深海平原
9. `petri-dish` — 阿西莫夫的培养皿（特殊观察场景，UI 中置于自然环境之后）

游戏首页环境轮播、Habitat Lab 预设与 `SCENE_LAYOUTS` 都保持这个顺序。上线前的主要工作是完善各环境的像素材质、专属小物件、初始布局、物种池和叙事，而不是继续增加环境 ID。

## 淡水腐殖池：五阶段物质循环

淡水腐殖池不再复用三日晨/午/夜节拍。正式运行固定为五个物质阶段，每阶段两轮、每轮四项，共十轮选择，围绕同一片叶子的物质变化推进：完整叶片 → 微生物加工 → 啃食与破碎 → 悬浮碎屑 → 再沉积为新的底面。玩家选择改变后续文字的观察框架（食物、遮蔽、位置记录），不决定腐解是否发生。

正式游戏与 Habitat Lab 共用 `scenery/freshwater-stages.mjs` 中的五套阶段布局。实验室切到 FRESHWATER 后显示 MATERIAL STAGE 下拉框，每个阶段可以独立拖拽和导出；导出文件带 `materialStage` / `stageId` 元数据，并使用 `habitat-layout-freshwater-pool-stage-XX-*.json` 文件名。正文与三个观察倾向结局维护在 `data/habitats/freshwater-material.mjs`。

## 接入顺序

1. 选定稳定环境 ID 和运行模式。核对路由是否针对已有 ID 写有专门分支；复制一份配置不能证明新模式可运行。
2. 按 [物种契约](species-data-contract.md) 对齐配置中的可玩池与物种的环境资格；按 [群体契约](cohort.md) 确定人数。
3. 对齐指标、默认值、演进逻辑、动作效果和叙事条件。普通水生正文通常依据 `days * 3` 验证；淡水腐殖池使用 `sequence: freshwater-material` + `turns: 10` 的无日夜五阶段物质循环；深海使用独立 `turns` 与对话路由。
4. 布景使用共享入口和已有像素规则；新增布局核对选择器、空间对象序列化与缓存依赖。纯渲染模块不负责写生态或存档状态。
5. 接入正文、结局池、选择界面及语言显示，并验证全部分支可达。新文字遵循 [叙事契约](narrative-contract.md)。
6. 验证旧档、新局、中途反馈重载、结局归档、环境切换和两个实验室。指标/状态形状变化按 [存档兼容](save-compat.md) 设计迁移。

运行统一检查，其中 `validate-habitats.mjs` 检查配置结构；实际演进、视觉与交互仍需 [扩展验证矩阵](expansion-guide.md#验证选择) 中的测试与浏览器检查。历史水景、场景和环境记忆笔记见 [历史索引](reference/README.md)。

## 地下水：一次补给过程，八次观察

`groundwater-pulse` 保留为旧存档的内部标识。公开界面不再使用 PULSE / 脉冲，而将一次补给过程整理为「渗水 → 涨水 → 携入 → 退水」，每阶段两轮三选一。它是水文事件启发的观察结构，不主张补给总会按固定时长或整齐四阶段发生。八段正文和各段焦点坐标在 `data/habitats/groundwater-observation.mjs`；旧四轮文案仍用于旧记录解码。

### 画面与叙事约束

- 洞穴专属群体为 14 只、原显示尺度的 0.5 倍；这只是宏观场景的展示密度，不是野外种群密度。入场改为寻找样本，每种一张带学名图。新增 Proasellus valdensis，与其余物种作比较展示，不主张同域共存。
- `scenery/groundwater.mjs` 将爬行、停顿与探触限制在布景中的湿面附近。石缝段只在同一入口遮挡和露出；不以屏幕近距离或水线相连证明动物穿过暗处。
- 涨水显示细水线与移动细粒；携入显示较明显碎屑；退水降低水纹和颗粒活动。生物膜段显示停走与前端动作，不声称像素画面能鉴定实际食物。
- 选择改变记录、手电位置和结局倾向，不使动物集体趋向食物，也不令光圈控制生态状态。常态和减少动态效果模式均保留缓慢动物活动；仅洞穴改变减少动态效果的原静帧策略。
- 原加减按钮改光圈直径（18–66%），中心按钮可按住拖动摇杆，点击回到当前观察区域，方向键微调。其他环境保留放大、缩小、复位。

### 资料与适用边界

- [Francois et al. 2016](https://doi.org/10.1111/1365-2435.12484)：对 P. valdensis 与 P. cavaticus 研究种群的同位素与食物实验支持沉积物生物膜的重要性；不将该结论推广到全部地下水等足目，也不把停留等同于摄食。
- [Pronk et al. 2009](https://pubmed.ncbi.nlm.nih.gov/19462487/)：补给后的渗流、储水释放、混合与颗粒输送；为水文事件叙事提供依据，而非给动物规定响应时间。
- [Henry & Magniez 1983](https://www.persee.fr/doc/linly_0366-1326_1983_num_52_10_10613?pageId=T1_335)：P. valdensis 的分类、分布、体长上限与细微鉴别形质。图像保留相近外观，不虚构夸张物种差异。
- [Magniez 1975](https://digitalcommons.usf.edu/ijs/vol7/iss1/8/)：S. virei 的非游泳习性与食物差异；不套用表层水生群体游泳。

### 验证与迁移

`tests/groundwater.test.mjs` 穷举 3^8 = 6,561 条路径，检查阶段指标、选择反馈、结局和存档重载，并覆盖旧四轮存档与减少动态效果下的湿面运动。`tests/browser/groundwater.mjs` 覆盖 Chromium / WebKit × 320、390、1440 宽，测试入场每种一图、14 个体、光圈、真实摇杆拖动、方向键、触屏定位、八轮与结局重载。

旧四轮记录按每轮完成一个阶段映射，保留原反馈和物种，补足新增展示个体；已完成结局保持完成。新记录保存 observationIndex，不再由晨午夜定位。旧的内部 pulse 文本键保留，以免历史笔记无法读取。

## 岩池：一轮潮汐观察

`intertidalVersion: 1` 使用 `data/narrative/intertidal.mjs` 的九次观察：低水、初涨、连通、藻枝托起、高潮、初退、石脊出现、回到湿面、再次低水。按钮选择观察对象，保留各自反馈；不改变潮汐或给观察行为打分。右上角显示从本轮低潮起算的 `00:00` 至 `12:25`，数值栏显示淹水相对指标、通水石隙和流势。九个采样点与数值是编排，半日潮周期背景见环境实验室的当前环境参考。

`scenery/intertidal.mjs` 按连续水位收放活动范围，复用原布局的藻丛和藤壶坐标；I. granulosa 可短距离游动，其他标本保持爬行和抓附。低动态设置降低动作速度但不中断步态、水纹或蔓足。新增动作仍使用已有游动、探触与爬行姿势，没有新增形态结构。形态实验室补入 I. granulosa 的栖地和游动依据；环境实验室补入周期与藤壶环境动画依据，布景编辑接口不变。

无版本号的旧岩池存档通过 `intertidalLegacy` 保留旧潮位、时间、剧情和结局，不重写过去的记录。新记录使用稳定的语言键，四种语言（含鼠妇语的数值）可在剧情、反馈、笔记及结局间切换。

验证：`tests/intertidal.test.mjs` 覆盖三种选择路径、完整周期、旧存档、低动态与活动范围；`tests/browser/intertidal.mjs` 覆盖 Chromium/WebKit、320/390/1440 宽度、四语言、刷新续玩与两个实验室参考。全环境动态回归仍由 `tests/browser/reduced-motion.mjs` 负责。


### 岩池标本与笔记扩充（2026-09-25）

岩池池选新增 `albifrons`（Jaera albifrons s.s.）与 `hirsuta`（Campecopea hirsuta），注册表追加在原 65 个条目之后。群体仍为七个个体，每次新抽取只包含一至两种；收集、笔记与存档沿用现有机制，已有群体不重抽。Jaera 的像素背形不提供种组内部鉴定；Campecopea 使用雌型轮廓，不把雄性的第六胸节长突当作成长动画。

两个新种的 BMIG 资料同时关联形态实验室当前标本参考与环境实验室当前环境参考。石下留水与较高岸位的藤壶岩隙是不同的庇护示意：退潮时 `hirsuta` 在水线以上的岩隙附近缩小活动，`albifrons` 沿仍有浅水的石边活动。动作是编排，不模拟空气暴露耐受时长、干燥存活或物种共存。

本场景七个品种的笔记统一重写为有留白的观察片段；不用第一人称集体代言，也不替动物断言被观看、命名或记住的需要。体长、微栖地、性别差异与绘制限制留在 `profile` 与实验室资料中；中、英、日文本分别编写，鼠妇语从中文版本编码。
