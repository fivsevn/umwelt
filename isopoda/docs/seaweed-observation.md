# 浅海藻场

九次连续观察，保留旧三日存档与既有收藏。新局使用 seaweedVersion: 1；旧记录和结局仍按原解码器读取。

## 共享几何与交互

`scenery/kelp-geometry.mjs` 为 layered kelp 输出整数像素、接触面、茎叶连接位置和深度。`scenery/shallow-marine.mjs` 负责附着、沿叶爬行、短距离转移和释放后的重新附着。几何每次更新只求解一次，绘制、遮挡和命中共享同一帧。根部固定，拖动控制局部弯曲，释放后回归自然流动。身体透明度不用于遮挡；被遮住的像素从可见绘制和命中区域中一起排除。

按住可见海藻直接轻拖，空白处保留原有视图移动，动物保留原有触摸/长按交互。取消指针和离开页面会结束手势。被抓起的动物暂时解除附着，放下后从当前位置寻找可达表面。减少动态模式同步减弱藻体摆动和动物运动。

九次观察的文本不把按钮意图当作已经完成的动作；换叶、完全遮挡、拨动的反馈读取当前观察期间的实际事件。切段保留连续运动。每轮抽取 2–3 种、共 18 只，上中下层分散附着；到达邻叶时避开过于拥挤的接触点。旧版七只的观察存档续玩时补足个体，保留原来的身份、种类和剧情记录；旧三日模式仍保持七只。

布局采用 22 株较细藻体。实际拨动超过阈值后，附着个体短暂收紧，最多两只出现气泡，其中一只可换到邻近叶片。同一手势不重复触发，个体有六秒冷却；这些是可读的扰动表现，不是情绪或物种特异反应阈值。第二段选择拨叶后沿用腐殖层的独立 interactionCue，完成后收起，并记住已学会的手势。

## 两个实验室

环境实验室共享同一藻体绘制、稳定对象 ID、变换、z 和 layered 参数。浅海预设的 FLOW 按钮预览自然摆动；“标本所在层”改变参考标本的遮挡深度，范围 0–100。数值越大越靠前；默认 45。导出 JSON 保留这些字段，旧 JSON 无 depth 字段时采用默认值。图层和编辑功能不改变游戏存档。

形态实验室的 I. balthica 当前标本参考新增食物/庇护实验，其他物种继续使用各自微栖地来源。环境参考列明柔性叶片、庇护和近缘种附着依据及适用范围。详细论文不进入 Credits 或游戏对白。
