# 花农时代 · 视觉样板 01

独立静态预览：陶盆、两层黑色金属花架、门与庭院壁灯。尚未接入游戏。

制作源稿、截图和规格见 [`docs/art/rooftop-pixel-01`](../../../docs/art/rooftop-pixel-01/README.md)。

从仓库根目录运行静态文件服务器，打开 `/rooftop/previews/pixel-01/`。页面可拖动、缩放、逐件查看、切换傍晚灯光和旋转。仅从本仓库加载资源；不需要 CDN、账号、后端或构建工具。

当前 Pages 自动发布仅监听 main。草稿分支可以在本地查看，截图可以直接在 GitHub 查看；此分支没有部署到正式游戏域名。

GLB 保存几何、法线和纹理坐标，PNG 单独共享。载入后由 `preview.mjs` 关联同一张图集，避免六个模型内嵌重复纹理。在通用 GLB 查看器中，模型会呈白色；Blender 源稿已打包贴图，可直接编辑完整材质。

`vendor/GLTFLoader.js` 和 `vendor/BufferGeometryUtils.js` 来自 Three.js 官方 r160。修改导入路径以桥接同版本的全局运行时，并改写一条示例 URL 注释，避免被现有发布脚本误认为实际资源。页面复用 `../../3d/vendor/three.min.js`，没有引入第二套 Three.js。版权许可见 `vendor/THREE-LICENSE.txt`。

第 7 版简化细小几何，将瓦缝、门板、污渍和材质层次直接画进 Pixelorama 原生粗像素。128×128 图集包含 16 个 32×32 材质区域；所有贴面展开为 8 像素/米的统一正方形格子。大、中、小盆分别烘焙尺寸后展开，实例缩放为 1。网页用共享贴图和四档恒定面顶点色，不使用连续光照、反光或软阴影。当前效果、近景、体积、原文件与考察记录见制作目录 README。
