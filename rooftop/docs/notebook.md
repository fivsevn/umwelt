# 东东的手帐与资料

[花农时代文档入口](../README.md)

游戏、车库和房间共用当前 294 件物品的手帐。正文依次展示客观描述、一句物件中心的人物随想，以及折叠来源；科学名只在植物名旁出现，换盆和换株形控制位于资料之后。制作笔记与目录分类不重复写入正文。

## 数据职责

| 文件 | 职责 |
| --- | --- |
| `rooftop/botany.mjs` | 植物与盆器的稳定 ID、科学名、别名、适盆规则和来源 |
| `notebook.mjs` | 资料描述、手帐呈现及换盆／株形控制 |
| `notebook-comments.mjs` | 已有研究物件的逐件随想 |
| `native-item-notes.mjs` | 当前家具和扩充陶瓷的描述与随想 |
| `item-data.mjs`、`item-catalog.mjs` | 当前物件目录及逐件 `sources`；供手帐与实际模型共同读取 |
| `firearms.mjs`、`weapons.mjs` | 枪械、兵器的既有资料与构造定义 |

名称、科学名、来源与视觉模型分别维护。当前视觉读取 `assets/items/` 的独立 Blender 模型和七张 Pixelorama 图集，制作源文件见[物品原稿](../art/rooftop-furniture-02/README.md)。

`item-data.mjs` 是生成文件：目录同步工具从 `rooftop/art/rooftop-furniture-02/preview/assets/catalog.json` 读取记录，补入实际模型与缩略图信息后导出。修改器物来源时同步上游目录记录，避免下一次导出覆盖；`notebook.mjs` 汇合植物、当前物件及所用花盆的来源，按 URL 去重。

## 来源边界

植物形态与照料资料来自 NC State Extension、RHS、NParks 等公开资料；地区名称与栽培说明使用日、台及中国大陆的园艺机构或植物数据库。属级、容器级通用资料在界面明确标作共用参考，不能写成某一物种的专属证据。

花果与株形为特征化表现，不能据此断言全部植物在同一季节开花结果。怕霜植物、冷凉作物、酸性介质与地区品种按实际资料注明适用条件。植物与盆器的限制以当前描绘尺寸及根系习性为依据，不把某种陶瓷传统写成植物学上的不适用。

窑口风格盆是游戏转译；有具体馆藏依据的陶器保留出处、年代、已知尺寸与适配说明。没有照片或测量的部位标明推定，改作栽培盆时注明排水孔属于游戏适配。详情见[器物资料](art-sources.md)。日用品不编造外部来源；仓库不嵌入第三方参考照片。

随想简短、客观而留白，不写人称代词、反问或固定归属句式。已有植物、盆器、收藏和兵器的资料保持稳定，不随视觉制作重新命名或分类。

## 操作与存档

公开页悬停 350 毫秒查看、点击固定；拖动和双指手势不打开手帐。关闭键与 Escape 合上，面板独立滚动；窄屏限高 44%，工具栏下方保留 8px，关闭键保持可点击。

所选花盆保存于 `object.pot`，种子和株形与陈列共同保存。撤销重做、复制、导入导出和三页面共享存档保留这些字段。手帐模型显示当前实际花盆与株形，目录缩略图显示各自默认组合。存档与承放规则见[维护与扩容](maintenance.md)和[承放关系](placement.md)。
