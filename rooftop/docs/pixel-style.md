# 花农时代像素制作管线

游戏采用完整 Blender 模型、Pixelorama 原生贴图和统一的最终低采样。入口与资源归属见[文档入口](../README.md)，实际页面检查见[综合场景测试](scene-review.md)。

## 制作原则

像素画风的模型仍须完成器形、比例、厚度、背面、底面、开孔和真实承放结构。纹理绘制在真实表面上，家具不为了让画面粗糙而额外删减几何。造型和几何只按明确的物件设计任务调整。

原稿细节、物理材料格与最终屏幕颗粒分别检查。Pixelorama 的最小像素格按实际长度统一，粗颗粒成品由共享低分辨率采样产生。不通过扩大笔触、缩小贴图或给单个对象追加像素化来代替最终采样。

修改前确认 PXO／Blend 与运行资源的对应关系。原稿保存并独立重开后，核对导出、游戏内接入和最终发布包；保护已有手改，不能直接回放制作脚本覆盖原稿。保存 Blend 不会自动更新网页模型。修改材料时保持模型、UV、镜头和存档契约，除非任务明确要求调整。

公开原稿前，检查 Blend 的打包图片路径、弱库引用、自定义属性和界面状态，以及 PXO 的导出目录。来源使用仓库相对路径，不保存个人绝对路径、私人地点或住宅地图坐标。清理元数据时须核对网格、UV、变换和打包贴图逐字节保持一致。

## 最终画面

正式游戏、车库及房间通过 `3d/outdoor-raster.mjs` 共用低分辨率离屏渲染，再按 `3d/pixel-grid.mjs` 的整数方格显示。游戏目标为 1.7 CSS 像素，每格实际边长为 `round(1.7 × devicePixelRatio)`：DPR 1 为 2 像素，DPR 2 为 3，DPR 3 为 5。相较上一版的 2.2 CSS 像素目标，高分屏上的颗粒稍细；DPR 1 保留 2×2 方格。车库与房间的目标继续为 2 CSS 像素，DPR 2 时为 4×4 设备像素，沿用原有采样。各页面中的场景、物品与角色共用整帧采样，方块保持完整；右边和下边不足一格的部分裁边，不拉伸。

建筑、光照、阴影、季节粒子和雨丝共用这次采样。邻居镜头的光学变形在最终方格取样时执行，遮罩与刻线沿用同一格，文字控件保持清楚。正式南北场景、车库与房间采用这条管线。后台测试页默认呈现原模型，可切换“游戏像素”核对最终效果；原模型模式使用完整设备像素，仍保留原生低模与最近邻贴图。目录缩略图维持独立的绘制预算。

狙击手镜头拉近时，按实际镜头视野逐步提高整幅画面的采样：从当前 1.7 CSS 像素的目标格缩小，最细目标为 1 CSS 像素，仍保留至少两个设备像素的完整方格（不超过默认格大小）。DPR 1 的默认格已达到两个设备像素的下限，拉近时保持这一格大小。近景比其他两个视角清楚，但保留细颗粒，不回到原稿的原生屏幕分辨率。建筑、物品、植物、东东、小猪、光影和空气特效一同变清楚，镜片遮罩、刻线、测距和拾取共用当帧像素格。拉远或切回小鸟／无人机后恢复原有颗粒；这两个视角的移动与接近不触发清晰度变化。模型及贴图的物理像素密度沿用原规格。

## 建筑材料

`3d/architectural-shell.mjs` 加载 Blender 导出的网格和清单，优先使用 `assets/background/empty-rooftop.bin.gz`，必要时回退到 `.bin`；导出与无损压缩步骤见[建筑原稿说明](../art/rooftop-lowpoly-02/README.md)。当前[建筑源文件](../art/rooftop-lowpoly-02/README.md)包含 `game-environment.blend`、真实 Pixelorama `terrace-book.pxo` 及远景 `distance-facades.pxo`。主图 `terrace-book.png` 为 1024×1024，标定 16 像素／米，单格边长为 0.0625 米；最近邻取样，不生成 mipmap。

地面、墙面、屋顶和远景按同一物理格检查，正面、侧面、背面、底面均核对 Blender 材料绑定。远景由 `baked-pixel-grid.mjs` 在原烘焙 UV 上取正交面格，窗灯数据图共享坐标。当前建筑采用平面着色、四档间接面光和 BasicShadowMap；太阳、发光窗与雾保留环境变化。

裂缝沿实际受力与接缝分支，修补保留新旧浆面的细微层次，水渍结合积水、墙根和排水位置绘制。使用细碎、连贯且不规则的材料痕迹，避免条带、平铺斑块和等间隔重复。

## 家具与现有物品

新家具沿用完整 Blender＋Pixelorama 工作流，物理材料格与建筑对照；当前独立家具模型为正方 16 像素／米。先检查源模型及贴图，再放进游戏三视角核对轮廓、承放、遮挡和最终颗粒。本地统一测试页的单独物件组检查完整物件，空场景组保持无陈列与角色。

新物品和房间背景分别使用 `rooftop/art/rooftop-furniture-02/`、`rooftop/art/rooftop-room-02/` 的独立 Blender 原稿及原生 Pixelorama 图集；完整面 UV 为 16 像素／米，通过 `ITEM_METRES_TO_UNITS = 5.6 / 3` 接入正式场景。人物共用材料继续使用[共用材质原稿](../art/rooftop-game/README.md)和 `assets/pixel/material-book.png`，由 `native-style.mjs`、`native-materials.mjs`、`native-book.mjs` 接入。世界单位与建筑米制坐标不同，不能将数值直接全局替换。

每个面在自身切平面上取正交方格，一格对应贴图的一个像素；模型长度、实例缩放和面倾角参与实际换算，不把整面拉伸到固定宽度。新原稿保存独立 face UV。现有布局继续沿用摆放、旋转、缩放、seed 和 ID 约定。

原生材质书 `material-book.pxo` 导出为 512×512 PNG，包含 215 个独立的 32×32 材料区域。Pixelorama 使用一像素 Pencil 和整数坐标，导出 PNG 与原生 cel RGBA 核对。木纹、氧化、湿生、布面磨损及器物内外壁按各自材质绘制，室内材料不统一套用室外污染。[器物与材质资料](art-sources.md)提供来源依据。

正式目录读取当前 GLB，完整内外壁、盆土、植物叶片和武器结构由当前 Blender 源模型检查。`rack-grid.mjs` 继续用于真实承放格栅判断，修改孔隙或厚度时同步核对承放。

物件夜间自发光只读取原稿中明确的 `finish: light` 标记，用于灯泡和发光面。`steel-light`、`wood-light` 表示浅色钢与浅色木材，不产生自发光。昼夜变化保留原贴图颜色；建筑窗灯继续使用独立的窗面与灯光遮罩。

建筑近景窗面由 Blender 对象的 `window_light` 标记导出为 `windowLight`，只有这些窗面参与夜间暖光。`glass`、`blue-glass`、`dark-glass` 是颜料分区，车辆玻璃、水面、衣物、实心门板和深色圆形构件不会因为共用分区而发光。远景沿用 `distance-lights.png` 窗灯遮罩，房间壁灯使用独立的 `room-lamp-glow` 标记。294 件物件的全部普通表面、四类灯具及建筑窗面分别检查昼夜变化。

`face-paintings.mjs` 提供正式模型的共用函数。2D 回退和图鉴绘制继续保持兼容。

## 空气与天气

柳絮、落叶、雪和雨使用真实世界坐标，保留稳定身份、远近层次、遮挡和连续轨迹。覆盖范围是小鸟、无人机、邻居三个游戏视角，包括移动、转头和变倍后的可见区域；邻居按有效圆形镜片分配预算。夏季蚊虫保持露台低位，雾按世界距离变化。天台、楼排、远处用于额外材料审核，不要求铺满特效。

8 种天气以 `overcast` 作为阴天规范值，`cloudy` 仅为兼容输入。光照、太阳方向、季节和天气资料见[环境制作说明](../art/rooftop-atmosphere-01/README.md)。实际页面与发布包核验见[维护与扩容](maintenance.md)。

人物第二版使用[方块原稿](../art/rooftop-actors-02/README.md)，全部服装与装饰保留。人物表面纹理统一为 16 像素／米，游戏与统一测试共用动作骨架和最终采样；原模型模式用于查看。
