# 花农时代统一测试

日常视觉调整的固定入口为 [`/rooftop/tests/browser/rooftop.html`](../tests/browser/rooftop.html)。从仓库根目录提供静态文件后，打开[本地页面](http://localhost:8765/rooftop/tests/browser/rooftop.html)。后续材料、光照和采样研究继续使用这个页面；页头的“东东与小猪 · 试衣”打开原人物测试页，目前用于[60 套时装与金棕中分的共享原稿](../art/rooftop-actors-02/fashion/README.md)。

## 三组内容

| 组 | URL 参数 | 内容 |
| --- | --- | --- |
| 场景 | `mode=scene` | 北天台、南阳台、空房间；完整建筑和环境，不放陈列物件或人物，可自由转看 |
| 物件 | `mode=item` | 全部 294 件物件图册，分类与搜索；点击同页近看实际模型，返回保留列表位置与筛选 |
| 初始组合 | `mode=game` | 读取固定初始布局，北天台 112、南阳台 15、房间 21 件，保留人物和承放关系 |

三组固定在同一视口，各组 renderer 和画布复用，共享运行资源。天气、月份、时间范围、节日预留、原生分辨率／游戏像素采样集中在同一页，统一读取当前正式原稿；切换采样保持当前取景和材料。初始组合未指定视角时默认无人机，起始高度为最高点降低两档，水平位置为基础机位后退两档；复位会恢复这组高度与距离。使用与正式游戏相同的沿檐、升降、靠近／退远和倍率按钮，可核对各观察视角的完整调节范围；场景组用于自由查看完整建筑。

物件组默认展开全部图册，按当前效果与环境实际绘制可见卡片，复用同一物件 renderer。点击卡片在同页转看完整模型，返回图册保留滚动位置、分类与搜索。后续建模、贴图和画面美术继续刷新这个固定页面查看。

原生模式为每个设备像素采样一次，模型和最近邻原稿贴图保持。游戏模式沿用共享最终整数像素格，建筑、光照、物件、人物和特效共用这次采样，规格见[美术管线](pixel-style.md)。物件源文件仍为实际 Blender 模型和 Pixelorama 原稿。

测试使用独立数据，不读取或改写个人陈列或换装存档。正式游戏、车库和房间继续使用原存储与承放规则；正式车库负责摆放、保存和导出。

主角北天台与南阳台使用与正式游戏、车库相同的[独立细化原稿](../art/rooftop-terraces-03/README.md)。空场景提供「当前天台／原建筑底模」比较，仅切换这份附加模型的可见性；初始组合始终使用当前天台。南北材料、补丁和圆形下水口按同一模型核对，原建筑沙盘、背景导出、邻楼、物件与房间保持各自原稿。

## 检查

核对三组切换、完整模型加载、取景、环境与采样往返、手机布局，以及个人存档保护。运行模块与 source 归属见[文档入口](../README.md)，空间天气契约见[空气说明](../art/rooftop-air-coverage-01/README.md)。

已准备 Playwright 和 Chrome 时，从仓库根目录运行：

```sh
ROOFTOP_REVIEW_ORIGIN=http://127.0.0.1:8765 node rooftop/tests/browser/rooftop-review-check.cjs
```

此脚本使用独立浏览器上下文，检查三组内容、实际模型、采样、环境与存档隔离。它使用 `ROOFTOP_REVIEW_ORIGIN`，不读取其他回归脚本常用的 `BASE_URL`；截图默认写入系统临时目录，也可通过 `QA_OUTPUT` 指定仓库外目录。当前 CI 的花农时代矩阵不自动执行此本地视觉检查。

环境选项的区间与来源见[崇川日历与天气](chongchuan-climate.md)。`weather=auto` 接入濠河附近实时天气，`weather=simulated` 使用季节模拟，其余天气值固定预览。实时模式只使用独立天气缓存，不读取个人布局。`month=1` 至 `12` 固定月份，`month=auto` 跟随北京时间月份；`festival=none` 默认关闭节日预览，`auto` 随现实日历，也可使用指定节日 ID。

测试页环境摘要和实时天气来源统一显示两位小数经纬度，不显示地区、景点名称。月份使用 `01月` 至 `12月`，日出、日落和天气观测时间使用 `HH:mm`。
