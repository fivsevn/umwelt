# 花农时代立体场景

独立观察地址 `/rooftop/3d/`，不增加原游戏入口。共享原页面的 `rooftop.css`、卡片流、音乐、居民活动、寻路、初始布置、花盆与植物资料、天气及本地时钟。北天台 95 件物品，南阳台 10 件；没有单独的布局副本或本机编辑存档覆盖。

拖动场景旋转，滚轮或双指适度缩放，点击原位置的门切换阳台。键盘方向键、加减和 Home 可操作视角。固定细像素，不提供额外控制栏。3D 模型为程序几何与低分辨率最近邻纹理，Three.js r160 从本地 vendor 加载，无外部 CDN、模型下载或真实天气服务。

阳台尺寸及物件的坐标、方向、缩放、盆器、种子直接来自原数据。三维植物使用对应物种的形态与色板，地面纹理由原像素画师生成。南北阳台共用一套住宅与屋顶关系，但前台只显示当前一侧；屋檐替代天台下的整栋六层立面。最小取景为当前阳台全貌，放大后可受限平移。周边只保留三栋近邻的局部，仍为氛围近似，不是建筑测绘。

从仓库根目录启动任意静态服务器后打开 `/rooftop/3d/`。发布由现有 Pages 流程完成，发布产物检查同时验证原页面与本页。`vendor/THREE-LICENSE.txt` 为 Three.js MIT 许可。
