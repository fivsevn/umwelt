# 观察者像素图标

小鸟、无人机、问号与八种操作使用 16×16 手绘图形。`observer-icons/observer-icons-atlas.pxo` 是真实 Pixelorama 原稿；修改后核对原稿、导出和页面效果。导出图集为 128×128 RGBA，透明背景，最近邻取样。

正式游戏的观察者和操作按钮统一为 22×22 CSS 像素正方形，保留浅色背景和 1px 阴影，不随横屏放大，按钮间距 3px。左下状态使用与右上环境信息相同的 9px 浅灰 Pixel 文字和 1px 偏移阴影，无背景；链接和操作使用前置 `>`，不加下划线。

正式页面的小鸟与无人机读取 `rooftop/assets/observers/observer-icons-atlas.png`，按可见轮廓裁去透明外边后缩小到 75%，在按钮内居中。小鸟取图集 `(2,4,13,11)`，无人机取 `(34,3,12,11)`，使用 `brightness(0)` 将已有轮廓统一为纯黑。方向箭头用 CSS 整数像素绘制，长度 7px；问号与加减使用 12px Pixel 字体字符。`rooftop/observer-ui.mjs` 集中定义可访问名称、操作与状态文字；观察者与操作均为独立的 `world-card`，每组同排显示，不另加外层面板。小鸟及无人机点击后更新左下角状态，问号沿用已有镜头机制。
