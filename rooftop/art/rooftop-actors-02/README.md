# 东东与小猪方块模型

现行人物原稿为 [60 套时装与配套小猪](fashion/README.md)。东东保留低模方块比例，使用棕金短中分、稍大且间距更宽的眼睛；正式游戏尺寸从原来的 1.10 调至 1.16。小猪身体、脸、鼻、眼、四足、耳朵和折角卷尾保持原型，每套只借用衣服的一部分。

运行目录是 `rooftop/fashion/`，房间、公开游戏手帐和本地试衣页共用资料与模型。旧的 35 套纯配色衣服及 35 款饰物退出当前目录，原稿可从 Git 历史找回，避免维护两套失同步的造型。`3d/resident-tools.mjs` 保留原手部道具和动作约定，水壶仍引用原生物品。

[本地试衣页](preview/index.html)与[统一测试](../../tests/browser/rooftop.html)不进入发布包。试衣页不读写玩家存档；正式房间继续与游戏共用换装记录。现行原稿、物理 UV、关节和 120 张缩略图的制作与验证方法见时装目录说明。

雨天使用独立的[透明雨衣外层](../rooftop-raincoats/README.md)，不替换当前时装或小猪配饰。
